## [Simon Willison uses GPT-6 Astra to auto-generate running routes from OpenStreetMap](https://simonwillison.net/2026/Sep/12/astra-running-routes/) ⭐️ 6.0/10

Simon Willison asked ChatGPT Work running on GPT-6 Astra \(Max\) to figure out 5K and 10K loop running routes from his home address using OpenStreetMap data; the agent worked autonomously for 27 minutes and returned an embedded map visualization plus downloadable GPX and GeoJSON files. When questioned, the model explained it used Nominatim to geocode the address and Overpass to download local OSM roads and trails before computing the loops locally. This is a first-hand demonstration that long-horizon agentic LLM tasks can now produce real, usable geospatial deliverables — not just text — by chaining external tools and open data sources over tens of minutes. It suggests that map-making, route planning, and other GIS-style workflows may increasingly shift from specialized software to general-purpose agents, while also exposing how opaque those agents can be. Willison notes a frustrating transparency gap: the actual Python code and intermediate steps were not visible in the ChatGPT UI, and once the thread had been compacted the model could no longer reproduce the code, which he calls an &quot;anti-feature&quot; and argues compaction systems should preserve and expose pre-compacted text via agent tool calls. The map display came from a built-in &quot;visualize&quot; skill that wrote an HTML file \(/workspace/el-granada-5k-share.html\) embedded in the UI, and he published a copy of that HTML as a GitHub Gist.

rss · Simon Willison · Sep 12, 23:56

**Background**: OpenStreetMap \(OSM\) is a free, openly licensed world map database built by volunteers and maintained by the OpenStreetMap Foundation; because its raw data is open, third-party services like Nominatim \(geocoding addresses\) and Overpass \(querying map features\) can be used programmatically. GPX is an XML-based GPS exchange format for waypoints, tracks, and routes, while GeoJSON is a JSON-based format \(standardized as RFC 7946\) for encoding geographic features such as lines and polygons. Together these standards let an agent turn raw map data into routes that can be viewed on a map and loaded onto a GPS watch or phone.
