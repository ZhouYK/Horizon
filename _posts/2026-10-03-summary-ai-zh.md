## [AI Agent 的 token 消耗量达人类 5 倍，KV cache 与内存压力骤增](https://news.google.com/rss/articles/CBMirgJBVV95cUxNVVVhN3dDRnN1RVBpNC1pMG52TTczcTNoc09VdkE3TUNZbmIxaXdnWXQ2WkM1cmJJNXVpQXk5U2RDWDZ0SEFNeHRuU2loS05SdTRacGlmUDdmMi1RSE5EXzhmcC13ZkhJS2stNll1UjNoOExkYnR1eHV5U0RoT1ptVzd3bzNOTW1obldoRW9JMFFvM3J3WjRZM2RaUHZYeGxMb2g1SWwxM1FhRmxHUXZBUER6SkkwaTRud2c5bGdTQlJQRmNXcG91c1FaVlNoNWpRc0plbk1VTDdtNDMycmJUUW1ZUHN2S1VUeXBnOTdBeks0QzBoUGJibHJDNkFGa0xpdDUyZjgyUGQwc05vSUh1emlnVGZOaEVTRWU1cWhUajM1WUpTVUJMRndYeVJ3UQ?oc=5) ⭐️ 7.0/10

Tom&\#x27;s Hardware 报道称，AI Agent 目前消耗的 token 数量约为人类用户的 5 倍，并且这一比例预计还会上升到 10 倍。主要原因是 Agent 大部分 token 都花在反复重读自己已经看过的上下文上，从而大幅推高了对 prompt 缓存和 KV cache 内存的需求。 由于 KV cache 在推理过程中要驻留在高速内存里，这种 token 膨胀会直接转化为每个并发 Agent 会话所消耗的更多 GPU 与系统内存，进一步加剧本已恶化的全球内存短缺。这会给推理服务商的硬件预算带来压力，并可能影响企业和开发者使用 Agent 式 AI 服务的成本与可获得性。 其核心机制是冗余重读：Agent 循环会反复重发相同的系统提示、工具定义和累积上下文，因此缓存的 prompt 和 KV cache 条目不断增长，而大量计算被浪费在模型已经处理过的内容上。KV cache 的大小随序列长度、批处理/并发量和模型规模增长，因此更长的 Agent 轨迹和更多并行 Agent 会使内存需求成倍放大，而非线性增加。

google\_news · Tom&\#x27;s Hardware · 10月3日 13:10

**背景**: 在基于 Transformer 的大语言模型中，KV cache 会保存已处理 token 的中间 key 和 value 计算结果，从而避免在每个解码步骤重复计算，是一项基础性的推理优化技术。Prompt 缓存则是相关技术，服务商通过复用已经处理过的 prompt 前缀，无需对相同 token 重复计费和计算。AI Agent 与聊天机器人的不同之处在于它会运行多步循环：调用工具、观察结果，再把不断增长的对话历史重新送回模型，这正是其 token 用量和缓存占用远超单轮人类交互的原因。

**背景**: “技术奇点”是一个假设中的未来节点：由能够自我改进的 AI 驱动的技术增长将超出人类的控制与理解能力，使结果变得难以预测。“共生”一词源自生物学，指的是两个物种之间长期互惠的关系。“人工共生智能”把这一隐喻套用到 AI 上，主张最有价值、也最安全的路径既不是纯人类智能，也不是纯机器智能，而是两者之间紧密耦合的伙伴关系。

google\_news · nytimes.com · 10月3日 12:00
