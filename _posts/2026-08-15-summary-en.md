It is the largest battery-electric aircraft ever flown. This milestone demonstrates that battery-electric propulsion is feasible at a meaningful scale and can dramatically lower operating costs for short regional flights. The ES-30 targets a 125-mile all-electric range and a 500-mile hybrid range, and the company relocated its headquarters from Sweden to Los Angeles in 2025.

## [Anthropic Shares Claude Code Tips: Prompt Caching Cuts Costs 90%](http://claude.md/) ⭐️ 7.0/10

Anthropic published a blog post with six cost-saving tips for Claude Code, claiming prompt caching can reduce token costs by up to 90%. The tips include running /clear between tasks, locking in model and reasoning effort at the start, using @ file references, adding silent flags to verbose commands, running /compact before leaving, and offloading large-output tasks to subagents. Token costs are a major friction point for developers using AI coding tools, with average daily spending around $13. These official, concrete optimization tips can directly lower usage bills and shape best practices across the Claude Code community. Anthropic notes that output tokens cost five times more than input tokens, while a cache-hit read costs only 0.1 times the normal input price, enabling up to 90% savings. The tips also warn that changing model or reasoning strength mid-session invalidates the prompt cache, and that the cache typically expires after one hour.

**Background**: Claude Code is Anthropic&\#x27;s agentic coding tool that uses large language models to assist with software development. Prompt caching is a mechanism that reuses already-processed tokens—such as system instructions, tool definitions, and file contents—to reduce cost and latency. The Model Context Protocol \(MCP\) is an open standard for integrating external tools with AI systems, and subagents are separate agent instances that handle focused subtasks within a Claude Code session.

## [US courts to disclose spyware surveillance counts in annual reports](https://techcrunch.com/2026/08/14/us-courts-will-start-publishing-how-often-the-government-uses-spyware/) ⭐️ 6.0/10

The US federal judiciary will begin counting and publishing how often judges approve spyware-based surveillance for real-time communications, starting with the 2028 Wiretap Report released in 2029. This is the first time such data will be collected. This marks the first time the public will have official data on the government&\#x27;s use of spyware for real-time interception, a practice that has been largely opaque. It enhances transparency and enables oversight of government surveillance, affecting privacy advocates, tech companies, and the public. The statistics only cover interception of real-time communications such as Signal and WhatsApp calls and messages via spyware; they do not include remote hacking that extracts photos, files, or location data from phones. The reports will break down numbers by federal and state judges, states, and types of crime, as in existing Wiretap Reports.

The change reflects the growing use of hacking tools by law enforcement to access encrypted communications.
