## [Anthropic 警告 Claude 用户：信息窃取木马劫持部分登录会话](https://www.aibase.com/news/30730) ⭐️ 8.0/10

Anthropic 已警告部分 Claude 用户，其设备感染了信息窃取型木马，导致活动会话令牌（session token）被窃取。攻击者利用被盗会话登录账户并窃取使用数据，因此 Anthropic 敦促受影响用户立即修改密码和凭证。 这很重要，因为被盗的会话令牌能让攻击者在不知道密码的情况下冒充用户，构成严重的账户接管风险。它也提醒人们，在使用 Claude 这类 AI 服务时，终端安全同样是保护账户的重要环节。 该木马专门针对活动会话令牌，属于会话劫持（session hijacking）的一种：攻击者获得有效令牌后，无需密码即可冒充合法用户。Anthropic 建议受影响用户及时修改密码和凭证，以防止进一步的数据泄露。

aibase · AIbase · 8月31日 18:01

**背景**: 在网络认证中，会话令牌是服务器在用户登录后签发的一串数据，客户端在后续请求中出示它，而不必重新发送账号密码。会话劫持指攻击者窃取或拦截这个有效令牌（通常是 Cookie 或认证 ID），然后冒充合法用户访问系统。由于令牌被当作已认证的凭证，它可能绕过密码甚至部分多因素认证保护。因此，短期有效的令牌、支持会话吊销以及及时发现设备中的恶意软件都是重要的安全措施。

## [AWS 推出 Agent Registry 预览版，统一管理智能体、工具与技能](https://news.google.com/rss/articles/CBMirwFBVV95cUxPWkQteXoyZjY2T3JVWFdkeEFOaUZBd0phcTNKbzlDZXFlNEI2aFNCYWNOaDIzd05HZTVJYm55b3h5ZzlxWW9JYmhmVjBzTENnR05nVVd4M2gxX2VOR2IwdG95b3dtY3VSTVNmb2V3dm1EYTNlYWNJckVMa0tYeW9EWU9uZ09xVWQwY2hKemdqdWhmZFBOR3N5WUpJNHdPRlh4ajlPR3YzUHl3dUh4bzEw?oc=5) ⭐️ 7.0/10

2026 年 4 月 9 日，AWS 宣布在 Amazon Bedrock AgentCore 中推出 AWS Agent Registry 的预览版。该服务提供集中式目录，帮助组织发布、整理和发现智能体、工具、MCP 服务器、技能以及自定义资源。 随着企业构建越来越多的智能体 AI 工作流，智能体、工具和技能容易变得分散且难以治理。AWS Agent Registry 提供统一的、可搜索的“唯一事实来源”，让团队复用经过验证的组件而无需重复开发，同时提升规模化治理能力。 该服务支持将 MCP 服务器、工具、智能体、智能体技能和自定义资源发布到可搜索的目录中，并提供整理与治理能力。目前它作为 Amazon Bedrock AgentCore 的一部分处于预览阶段。

google\_news · Amazon Web Services \(AWS\) · 8月31日 19:18

**背景**: AWS Agent Registry 是 Amazon Bedrock AgentCore 的一部分，后者是用于构建和运行 AI 智能体的托管环境。在现代智能体架构中，智能体需要借助工具（tools）和技能（skills）来执行任务，但这些资产往往分散在不同团队和系统中。通过集中式注册中心，组织可以统一编目和共享这些组件，这也是大规模、安全地运行多智能体系统的关键。
