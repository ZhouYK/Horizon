## [小米发布三款玄戒芯片，宣称多项行业第一](https://mp.weixin.qq.com/s/ceIQbNnZrcNQqGywXCiXTQ) ⭐️ 8.0/10

小米发布了三款新的玄戒芯片：AI 旗舰 SoC 玄戒 O3、高带宽 AI 加速芯片玄戒 O100，以及国内首款 3nm 智驾 AI 芯片玄戒 D100。据称三款芯片均已完成回片验证，其中 O3 宣称是全球首款支持 LPDDR6 内存的移动处理器，内存带宽达 113.8 GB/s。 这标志着小米在手机、端侧 AI 和汽车领域自研芯片的强势推进，可能对高通和联发科构成挑战。若这些宣称属实，小米将降低对外部芯片供应商的依赖，并加速其生态内端侧 AI 的普及。 玄戒 O3 采用十核全大核 CPU，多核跑分首破 15000 分，GPU 为 G2-Ultra NX，性能提升 85%、功耗下降 64%。玄戒 D100 集成 20 核 CPU 与 16 核 NPU，最高支持 160GB 统一内存，可本地部署 200B 参数大模型，明年投入商用。玄戒 O100 采用 6nm 晶圆级垂直堆叠封装，混合键合间距 1.4 微米，带宽达 1.22TB/s。

## [Grok bot 0.18.0 误开 source maps，源码被重建并开源](https://x.com/b_nnett/status/2091630242792112480) ⭐️ 6.0/10

Cursor 团队发布的 Grok bot 0.18.0 意外开启了 runtime source map，网友 Bennett 据此重建出完整后端源码并上传 GitHub。重建版可配合官方前端使用，还可修改，并新增了 Codex 和 Claude Code 自定义路由，以及用本地 Docker 代替远程沙箱的功能。 这一事件凸显了错误配置的 source map 可能泄露专有后端逻辑，使一次小发布失误演变成完整源码泄露。它也展现了闭源 AI 工具与开源社区之间既对抗又互补的关系——社区会重新实现并扩展这些工具。 泄露的构建版本不含前端，但可以使用官方打包的前端启动，且仍可修改。Bennett 在基础上加入了 Codex 与 Claude Code 自定义路由，并支持用本地 Docker 代替远程沙箱。

telegram · zaihuapd · 8月24日 10:36

**背景**: Source map（源映射）是一种将压缩或转换后的代码映射回原始源文件的文件，常用于调试；如果在生产环境开启，可能会无意中暴露可读源码。Runtime source map 专门覆盖运行时生成或转换的代码，使得重建后端逻辑变得更加容易。Grok Bot 是 xAI 推出的 AI 智能体，已集成到 Cursor 中，可在云端沙箱中执行编码任务；Codex 和 Claude Code 则是同类 AI 编程助手。

## [Netflix 据报考虑在应用内接入第三方流媒体服务](https://www.theverge.com/streaming/983741/netflix-open-app-peacock-fox-one) ⭐️ 6.0/10

据《纽约时报》报道，Netflix 高管最近讨论了在 Netflix 应用内直接整合 Peacock、Fox One 等第三方流媒体服务。目前没有即将达成的交易，也尚不清楚是代售订阅还是整合内容。 如果 Netflix 从纯粹的竞争者转变为聚合平台，可能会改变消费者发现和付费观看流媒体的方式，使其应用可能成为多种服务的一站式入口。这一动向也可能促使其他流媒体公司重新考虑分发合作，加剧对用户注意力的争夺。 今年 6 月，Netflix 在法国试点将本土电视台 TF1 的直播频道和内容接入应用，联席 CEO Greg Peters 7 月表示合作成果令人鼓舞，并暗示会考虑类似交易。不过，未来潜在美国交易的具体形式，无论是代售订阅还是直接整合内容，目前都尚未确定。

telegram · zaihuapd · 8月24日 15:50

**背景**: 传统上，各流媒体服务都是独立应用，需要分别订阅，因此把它们聚合到 Netflix 应用内将是一个重大的战略转变。Netflix 过去主要依靠自家的片库和原创作品，在应用内接入竞争对手的内容，将标志着它可能向类似传统有线电视捆绑包的平台方向演进。法国 TF1 试点是该公司首个公开可见的此类整合案例，但商业条款的细节仍然很有限。
