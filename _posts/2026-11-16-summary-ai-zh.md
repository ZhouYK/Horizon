Simon Willison 发布了 datasette-maplibre 0.1a0，这是一个 alpha 阶段的 Datasette 插件，使用 MapLibre GL JS 库和免费的 OpenFreeMap 矢量瓦片服务器来渲染地理空间数据。Willison 表示，其中大部分内容是他通过一段发给 Claude 的提示词完成的：他让模型先研究 datasette-cluster-map 和 datasette-leaflet-geojson 两个插件，再把它们的功能与 MapLibre、OpenFreeMap 结合起来。 这是相当长一段时间以来首个新的 Datasette 地理空间插件，它把现代 WebGL 渲染器与无需 API key 的免费瓦片源结合起来，让一度沉寂的插件生态重新活跃起来。它同时也是一个值得关注的 AI 辅助开发案例：一个功能相当丰富的插件，主要来自一段提示词，而非长期的手工实现。 该插件目前只是 0.1a0 早期 alpha 版本，其接口和行为预计还会变化。在“跳出框框思考”这一指令带来的若干点子中，Willison 最喜欢的一点是：插件先为 GeoJSON 图形渲染 SVG 预览，只有当它们滚动进入可视区域时才加载开销更大的 WebGL 预览；此外还有一个完整演示可以运行在 Datasette Lite 中，借助 Pyodide 和 WebAssembly 直接在浏览器里加载插件与演示数据库。

rss · Simon Willison · 11月15日 23:58

## [Datasette 1.0a43 发布：新增流式渲染器与安全修复](https://simonwillison.net/2026/Nov/15/datasette/) ⭐️ 6.0/10

Datasette 1.0a43 为输出渲染器引入了流式支持，内置的 CSV 与 TSV 导出以及插件都可以通过新增的 Response.stream\(\) 方法一次性流式输出表中的每一行。该版本还包含两项安全修复，其中一项严重到单独发布了 GitHub 安全公告（GHSA-mw6v-83vp-7c4c），涉及私有存储查询的标题和 SQL 可能被泄露的问题；此外还重新设计了行页面的 JSON 表示、新增 &lt;datasette-copy-button&gt; Web Component、DatasetteModal.confirm\(\) JavaScript 工具方法以及 CSS 跨文档视图过渡。 流式输出是通往 Datasette 1.0 道路上剩余的最大一项工作，它让 CSV 导出变成普通渲染器，从而移除了大量特例代码，同时简化了核心与插件开发。安全公告同样重要：任何运行着含私有存储查询的 Datasette 实例的运维者都应尽快升级，即使被泄露的查询无法被执行。 1.0 里程碑目前完成度为 53%，Simon Willison 表示他大量借助 Claude Fable 5.2 来清理待办事项。流式 API 通过 register\_output\_renderer 插件钩子和 Response.stream\(\) 内部方法暴露；新增的视图过渡被包裹在 prefers-reduced-motion: no-preference 媒体查询中，因此关闭动画的用户不会受到影响。

rss · Simon Willison · 11月15日 23:20

**背景**: Datasette 是由 Simon Willison 开发的基于 SQLite 的开源 Python 工具，用于探索和发布数据，其功能通过基于 pluggy 的插件钩子系统进行扩展。输出渲染器是负责把查询结果转换成 CSV、TSV 或 JSON 等格式的插件，在此版本之前它们必须将所有行缓冲在内存中，而无法流式输出。1.0 里程碑是一项长期工作，目的是在最终正式版发布前稳定 Datasette 的各类 API——这些 API 已在 alpha 状态停留多年。
