## [Meta 发布 Muse Wonder 系列前沿模型，订阅价 20 美元起](https://research.meta.ai/blog/muse-wonder) ⭐️ 8.0/10

Meta 正式发布 Muse Wonder 与 Muse Wonder Full 两款前沿模型，即日起通过 Meta Model API 与 Muse Code 开放，并通过 Muse 应用以每月 20 或 100 美元的订阅价提供。Meta 称新模型在对标 OpenAI 与 Anthropic 领先模型时具备竞争力，并新增 Active Memory 与 Active Focus 两项能力以减少智能体偏离目标。 这标志着 Meta 正式以付费订阅方式进入前沿模型商用市场，从以往的开源权重路线转向与 OpenAI、Anthropic 正面争夺订阅收入。对开发者和企业而言，选择前沿模型的清单上又多了一个重要选项，这可能会对整个细分市场的定价形成压力。 Muse Wonder Full 仅面向 Muse Code 订阅用户开放，月费为 50 或 200 美元，而较低价位档位通过 Muse 应用以每月 20 美元起售。Meta 表示未来将用该系列模型驱动其 Muse AI 智能体，但尚未公布具体时间，也未披露基准测试成绩或技术细节。

telegram · zaihuapd · 10月12日 17:32

**背景**: Meta 此前主要依靠开源权重的 Llama 系列参与大模型竞争，因此 Muse Wonder 标志着它转向闭源、订阅制的前沿模型。所谓智能体（agent）任务，指模型能够自主规划并连续执行多步操作；新加入的 Active Memory 用于记住用户的偏好与上下文，Active Focus 则在长时间任务中让智能体持续聚焦于既定目标。Meta Model API 是 Meta 面向开发者提供的模型调用接口，Muse Code 则是面向编程场景的订阅产品。

## [丘成桐牵头在清华成立数学与人工智能实验室联盟](https://www.beijing.gov.cn/fuwu/lqfw/gggs/202610/t20261012_4897748.html) ⭐️ 7.0/10

菲尔兹奖得主、清华大学讲席教授丘成桐牵头联合多家机构，于 10 月 11 日在清华大学正式成立丘成桐数学与人工智能实验室联盟，并由丘成桐本人担任主席。该联盟汇集了来自多家机构的 1000 多名科学家，目标是自主开发中国数学专用大模型。 这一举措释放出重要信号：中国有意在“AI for Mathematics”这一方向上直接参与竞争，而该领域此前已由 Google DeepMind 的 AlphaProof 与 AlphaGeometry 取得奥数级别的成果。若联盟能推出具备竞争力的数学专用基础模型，可能改变数学研究的工作方式，并强化中国在人工智能与基础科学两方面的地位。 联盟表示将重点研发数学专用模型、建设 AI 辅助数学研究的基础设施，并进一步拓展至量子计算、生命科学、金融经济等交叉领域。丘成桐将 AI 对数学的冲击形容为“像海啸来了”，主张应主动“冲浪”而非回避。

telegram · zaihuapd · 10月12日 03:00

**背景**: 菲尔兹奖常被视为数学界的诺贝尔奖，丘成桐于 1982 年获奖，是推动中国 AI 研究的最具影响力的数学家之一。Qwen2.5-Math 等数学专用大模型通过思维链推理来求解数学问题，而 Lean 这类形式化证明助手则能让计算机逐步验证证明的正确性。2024 年 7 月，Google DeepMind 的 AlphaProof 与 AlphaGeometry 成为首个在国际数学奥林匹克竞赛中达到银牌水平的 AI 系统，表明 AI 已能处理前沿的数学推理任务。

## [OpenAI 将 GPT-6.1 Sol 默认上下文提升至 500k tokens](https://x.com/thsottiaux/status/2109430343346581527) ⭐️ 6.0/10

在 OpenAI 连续 28 天更新的第 7 天，OpenAI 将通过 Codex 和 Work 使用 GPT-6.1 Sol 时的默认上下文长度从 272k 提升至 500k tokens，增幅约 80%，且不额外收费。用户仍可手动调高或调低该设置，可配置的最大上下文长度仍为 1M tokens。 更大的默认上下文窗口可以减少长会话被压缩或截断的频率，从而直接惠及 Codex 中长时间运行的编码智能体，以及 Work 中多步骤的文档与业务工作流。同时，这一免费调整也抬高了其他大模型厂商在长上下文能力上的基准线。 500k 的默认值经过测试，被认为适合多数用户；而重度用户仍可将窗口调高至 1M tokens 的上限。该调整仅适用于通过 Codex 和 Work 使用的 GPT-6.1 Sol，且官方公告本身较为简短、偏宣传性质，并未说明这一扩展是如何实现的。

telegram · zaihuapd · 10月12日 00:09

**背景**: 大模型的上下文窗口指的是模型在单次请求中能够处理的 token 总量（一个英文 token 大致相当于 3–4 个字符），输入与输出都计入其中。当对话或智能体轨迹超出该上限时，系统必须压缩、摘要或丢弃较早的内容，这正是长会话容易遗忘既有决策、重复劳动的原因。GPT-6.1 Sol 于 2026 年 9 月 29 日发布，被 OpenAI 定位为在能力与成本之间取得新平衡的日常专业工作模型，在代码编写与调试、文档理解以及多步骤业务流程上相较 GPT-6 Sol 有明显改进。

## [DeepSeek 拟领投前腾讯科学家创立的 Winverse AI，投后估值约 4 亿美元](https://www.bloomberg.com/news/articles/2026-10-12/deepseek-backs-ex-tencent-ai-scientist-s-400-million-robot-lab) ⭐️ 6.0/10

知情人士称，DeepSeek 拟领投前腾讯科学家 Hu Han 创立的机器人 AI 初创公司 Winverse AI，种子轮金额达数千万美元，投后估值约 4 亿美元。美团的龙珠资本等投资方也已承诺出资，但交易尚未最终敲定。 这将是 DeepSeek 迄今规模最大的初创投资之一，也表明这家大模型领域的重要玩家正在向具身智能与机器人方向扩张——中国 AI 公司日益把这一方向视为下一个前沿。一个机器人方向的种子轮就达到约 4 亿美元投后估值，也说明资本正在激烈争抢从大厂出走、投身物理世界 AI 的人才团队。 该交易尚未最终敲定，估值与参投方名单仍可能发生变化。DeepSeek 此前还入股了宇树科技（Unitree），这说明本次投资更像是一套组合布局的一部分，而非单点押注。

telegram · zaihuapd · 10月12日 14:59

**背景**: DeepSeek 是一家以大型语言模型闻名的中国 AI 公司，近来开始把资金投向机器人初创企业。Winverse AI 是由前腾讯科学家 Hu Han 领导的机器人 AI 初创公司，目前处于早期阶段，公开可查的成果与产品信息很少。所谓具身智能（embodied AI），指的是嵌入物理实体中的 AI 系统：它通过传感器感知周围环境，通过执行器采取行动，并自主追求目标——这正是让机器人能在真实世界中（而不只是在软件中）运作的核心技术。
