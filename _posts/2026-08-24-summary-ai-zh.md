## [你的可执行文件就是 SQLite 数据库](https://simonwillison.net/2026/Aug/24/your-executable-is-a-sqlite-database/) ⭐️ 8.0/10

Farid Zakaria 展示了一项技巧：构造一个既是 SQLite 数据库、又能作为 Linux 可执行文件运行的文件。将 SQLite 的 4 字节应用 ID 设为 &\#x27;SELF&\#x27;，并把 ELF 组件安排到多张 SQLite 表中，最终文件可以通过 binfmt\_misc 机制直接被内核执行。 这个技巧展示了 SQLite 和 Linux binfmt\_misc 机制的灵活性，为将应用程序与数据打包成单一文件提供了富有创意的可能性。虽然它更多是巧妙的炫技而非范式转变，但可能为系统与软件工程带来新的设计灵感。 SQLite 的应用 ID 是文件偏移 68 字节处的 4 字节字段，此处被设为 &\#x27;SELF&\#x27;（Structured Executable &amp; Linkable Format）。ELF 的各组成部分按 self.sql 中的 schema 存放在 SQLite 表里，C 编写的 self-exec 解释器会在被 binfmt\_misc 调用时提取并执行这些部分。

rss · Simon Willison · 8月24日 11:38

**背景**: SQLite 应用 ID 是数据库文件头中的一个 4 字节整数，用于标识文件类型，通常需要向 SQLite 开发团队注册。ELF 是 Linux 上标准的可执行文件格式。binfmt\_misc 是 Linux 内核的一种能力，可让任意可执行文件格式被识别并转交给用户态解释器处理。这项技术将三者结合，把 SQLite 的结构映射到 ELF 组件，并借助 binfmt\_misc 触发执行。

**背景**: 混合键合是一种先进封装技术，通过芯片或晶圆之间的直接铜-铜连接取代传统凸点，可在 10µm 以下的间距实现更高互连密度、更高带宽和更低功耗。晶圆级垂直堆叠则通过多层晶圆或芯片堆叠来缩短信号路径、提高集成度。端侧大模型推理指在手机、汽车等本地设备上直接运行大语言模型，而 TPS（tokens per second，每秒令牌数）是衡量推理速度的常用指标。
