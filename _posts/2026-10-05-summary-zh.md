## [2026 年诺贝尔生理学或医学奖授予光遗传学发现者](https://www.nobelprize.org/all-nobel-prizes-2026/) ⭐️ 8.0/10

2026 年诺贝尔生理学或医学奖授予卡尔·戴瑟罗特（Karl Deisseroth）、彼得·赫格曼（Peter Hegemann）和格奥尔格·纳格尔（Georg Nagel），以表彰他们发现光控离子通道并开创光遗传学。该奖项肯定了让研究人员能够用光在活体大脑中开启或关闭单个神经细胞的技术。 光遗传学把神经科学从以观察为主的研究，变成了可以主动干预的实验科学——研究者不再只是记录神经活动，而是能因果性地检验哪些细胞驱动了哪些行为。如今它已被全球众多实验室采用，并被探索用于恢复退行性失明患者光感等临床用途，因此这次诺奖标志着该技术已成为脑科学与生物技术的核心工具。 赫格曼和纳格尔在 2000 年代初于单细胞绿藻中发现了光敏离子通道 Channelrhodopsin-1 和 Channelrhodopsin-2，而戴瑟罗特在 2005 年前后证明这类蛋白可以表达在哺乳动物神经元中，充当由光触发的开关。该技术仍需要对细胞进行基因改造，在动物实验中还需植入光纤，且光散射限制了作用深度与精度，因此目前多数应用仍停留在基础研究，而非常规人类疗法。

## [OpenAI 将在欧盟为 AI 生成文本添加隐形水印](https://openai.com/index/eu-text-provenance/) ⭐️ 7.0/10

OpenAI 宣布，为满足《欧盟人工智能法案》的内容透明要求，未来几周将在欧盟地区符合条件的 ChatGPT 和 Codex 文本输出中加入机器可识别的隐形水印。API 用户可为部分模型选择开启水印功能（默认关闭），同时 OpenAI 开放研究人员和专业机构申请使用文本水印检测器。 这是主要模型厂商首次大规模落地文本来源标记的举措之一，把《欧盟人工智能法案》的透明义务变成了实际的工程要求，其他厂商很可能不得不跟进。此举将影响欧盟地区的 ChatGPT 用户、基于 OpenAI 模型开发的 API 开发者，以及需要可靠区分 AI 生成文本与人类写作的研究人员。 该水印对读者不可见、只能由机器检测，对 API 用户属于可选功能且默认关闭，且仅覆盖部分模型；检测器项目只向研究人员和专业机构开放，普通公众无法直接使用。

telegram · zaihuapd · 10月5日 15:25

**背景**: 文本水印通常是在生成过程中轻微地调整模型的用词偏好，使文本带上一套只有厂商自家检测器才能可靠识别的统计模式，而不是插入肉眼可见的标记。《欧盟人工智能法案》正在分阶段实施，要求提供商让 AI 生成内容可被识别且保持透明，这促使各厂商采用水印这类来源标识手段。由于此类标记可能被编辑或改写破坏、去除，检测本质上是概率性的，通常在较长且未经修改的文本上效果最好。

## [OpenAI 称 GPT-6 Astra 与 GPT-6.1 Sol 默认速度提升约 50%](https://x.com/thsottiaux/status/2107158998495748264) ⭐️ 6.0/10

据 Tibo 发布的消息，OpenAI 将其 GPT-6 Astra 和 GPT-6.1 Sol 模型的默认推理速度提升了约 50%，从大约 30 TPS（每秒 token 数）提高到 50 TPS。该变化据称覆盖所有产品以及使用 Sign in With ChatGPT 的合作方，用户无需任何操作，预计约两小时内即可感知；同时模型采用了更优化的分词器，完成任务所需的 token 数量也有所减少。 生成速度是用户对 LLM 产品最直观的感受之一，因此默认吞吐量提升约 50% 对所有基于这些模型开发或直接对话的用户都有实际收益，且无需改代码或额外付费。配合降低 token 消耗的优化分词器，它还可能降低延迟敏感型应用（例如智能体和编程助手）的实际成本与响应时间。 TPS（每秒 token 数）衡量的是首个 token 之后的生成速率，在很大程度上决定长回答的端到端延迟，因此从 30 TPS 提升到 50 TPS 对长文本输出意义明显。不过这一说法来自一条简短的社交媒体二手转述，没有基准测试、方法论或第三方验证，且涉及的模型名称相对于目前公开的 OpenAI 发布版本似乎属于“未来型号”，因此具体细节应视为未经证实。

telegram · zaihuapd · 10月5日 17:38

**背景**: TPS 是衡量 LLM 推理速度的常用指标，表示模型在开始生成后每秒产出的 token 数量，通常与衡量响应快慢的 TTFT（首 token 延迟）配合使用。token 是模型读写文本的子词单位，而分词器就是负责把文本切分成 token 的组件，因此分词器更优意味着同一任务消耗的 token 更少，所需时间与成本也随之下降。Sign in With ChatGPT 是 OpenAI 的身份登录体系，允许用户用 ChatGPT 账号登录支持的第三方应用，这也是此次速度提升能覆盖合作方产品的原因。
