## [Claude Fable 5.1 Launches With Big Science Gains and a Pelican Test](https://simonwillison.net/2026/Sep/1/claude-fable-5-1/) ⭐️ 9.0/10

## [Paint.NET Creator Details Claude-Coded Direct2D Reimplementation for Wine](https://simonwillison.net/2026/Sep/2/rick-brewster/) ⭐️ 8.0/10

Rick Brewster announced that Paint.NET now includes an internal, from-scratch, clean-room reverse-engineered rewrite of Direct2D, used when the app is launched with the /wine flag on Wine. Roughly 180,000 lines of this implementation were generated by Claude AI, which Brewster says made the whole effort possible. This matters because it demonstrates a large-scale, real-world use of an LLM for reverse engineering and code generation, far beyond small snippets. It also highlights both the promise and the risk of AI-assisted development, since such code may revive Windows apps on Linux but is hard to thoroughly review. The new code lives in PaintDotNet.Windows.Direct2D1.Managed.dll and is triggered by the command-line switch /wine. Brewster noted that Claude sometimes needed close supervision, such as initially omitting the COM equivalent of AddRef\(\) for reference-counted objects, but it also did impressive reverse engineering of the formulas behind Direct2D&\#x27;s built-in effects library.

rss · Simon Willison · Sep 2, 05:50

**Background**: Paint.NET is a popular Windows image editor, and Wine is a free compatibility layer that lets Windows software run on Unix-like operating systems without emulation. Direct2D is Microsoft&\#x27;s hardware-accelerated 2D graphics API, and Wine has never implemented it well enough for Paint.NET&\#x27;s needs. Vibe coding, a term coined by Andrej Karpathy in 2025, refers to AI-assisted development where code is accepted without thorough review, relying instead on results and follow-up prompts to drive changes.

## [Anthropic reorganizes Claude system prompts, adds strict song lyric ban](https://simonwillison.net/2026/Sep/2/claudes-new-system-prompt/) ⭐️ 7.0/10

Anthropic has reorganized its published Claude system prompts into a per-model index, with separate pages for models such as Haiku 4.5 and Fable 5.1. Notably, the new Fable 5.1 prompt includes a lengthy prohibition on reproducing song lyrics, poems, or passages from books and articles. Simon Willison documented the change on September 2, 2026, and highlighted how the docs site&\#x27;s .md suffix makes it easy to diff prompt revisions. System prompts define an LLM&\#x27;s behavior, constraints, and output style, so publicizing their changes increases transparency about how Claude is controlled. The new copyright-focused rule also signals how AI labs are responding to legal pressure from the music and publishing industries. The rewritten rule says Claude must not reproduce song lyrics, poems, or excerpts from books and articles &quot;in whole or in part,&quot; including last lines, choruses, hooks, note-by-note melodies, or lines a user pastes and claims as their own. It also says that once Claude declines such a request in a conversation, it continues declining narrower or reworded versions for the rest of the conversation, and offers to describe or analyze the work instead; works first published before 1929 are allowed.

rss · Simon Willison · Sep 2, 14:16

**Background**: A system prompt is a special initial instruction given to an LLM before user queries, defining the model&\#x27;s role, behavior, tone, constraints, and boundaries. It acts as an invisible foundation for conversational AI, and even small edits can significantly change outputs. Anthropic has chosen to publish system prompts for Claude.ai and its mobile apps, along with historical changes, as a transparency measure. The docs site also supports adding .md to any page to retrieve Markdown, which makes it easier for developers and researchers to compare prompt versions.
