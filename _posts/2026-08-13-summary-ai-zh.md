谷歌 DeepMind 推出了多语言手语转文本模型 SL2T，并通过 Gboard 和 Live Transcribe 集成到 Pixel 11 智能手机中。这是首个进入消费级手机功能的手语 AI，首发支持美国手语。 这一里程碑让手语 AI 走进普通用户，显著改善了聋人和听障人士的沟通方式。它也证明了在手机上运行复杂多语言模型的可行性，为未来机型奠定了基础。 SL2T 在 10 万小时手语视频上训练，其中约四分之一来自美国手语数据集。跨语言联合训练提升了识别效果，尤其对资源较少的手语帮助明显，Pixel 11 上该功能无需额外付费。

aibase · AIbase · 8月13日 14:53

**背景**: 手语识别很困难，因为系统必须解析连续且多变的手势、面部表情和身体动作。SL2T 采用跨语言联合训练，即在语言之间共享知识，使 ASL 等资源丰富的语言能帮助提升资源不足手语的识别效果。这是此类模型首次嵌入消费级手机。

## [AWS 推出 Amazon Bedrock AgentCore 浏览器工具，实现传统 Web 应用自动化](https://news.google.com/rss/articles/CBMivwFBVV95cUxQZEZhQ0J1Sno1RFhCWmtGS1RoTTJmR3g1d0E0bVVTMXRUNm1KVTR3UEJBSDlfSU9BWlZzYUlhZnNfUFd6MGVORG1TM3V0LTFycGpTS3pmb1JoeXdBcXJiRWlSLW5oVTNuLWIxT3ZqTUdfQ003T0xzQ0lYWnVDMDY3NDFaRjBpamp0R2ltQldfdjh6RnBrSGNMNjhUUHVZMHFvUV9RTGJFOXJraVgtU2tOcHdhUmtwbkZCR084RUtVYw?oc=5) ⭐️ 7.0/10

2025 年 8 月 1 日，AWS 发布了 Amazon Bedrock AgentCore 浏览器工具（AgentCore Browser Tool），使 AI 代理能够以基于会话、可观测的方式与 Web 应用交互、填写表单和浏览页面。该工具旨在通过云上浏览器自动化来自动化缺乏 API 的旧版 Web 应用。 这一发布意义重大，因为它使组织能够将 AI 代理应用于难以通过 API 集成的旧系统，从而减少人工劳力并实现工作流程现代化。它还解决了基础模型对实时数据访问的限制，并标志着 AWS 致力于将基于代理的浏览器自动化推广为企业主流能力。 AgentCore 浏览器提供基于会话的网页浏览及全面可观测性，其工作流程包含四个关键步骤，首先是创建 Browser Tool。根据第三方示例，它可以与 Strands 等框架配合使用，通过预先构建的 AgentCoreBrowser 工具调用，旨在解决基础模型需要实时数据访问时的局限。
