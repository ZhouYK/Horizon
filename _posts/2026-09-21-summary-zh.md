## [中国监管收紧：人形机器人 IPO 热潮被按下减速键](https://www.reuters.com/business/finance/china-slows-humanoid-robot-ipo-rush-hype-outruns-reality-2026-09-21/) ⭐️ 7.0/10

中国监管部门正通过非正式的“窗口指导”放缓人形机器人企业的 IPO 进程，提高审批门槛，要求企业证明真实的部署规模、订单量与商业可行性，而非依靠炒作推高估值。知情人士称，宇树科技上市初期股价剧烈波动是这轮审查收紧的诱因，目前至少还有 6 家中国人形机器人企业正准备上市。 这一举动标志着监管思路从奖励“概念炒作”转向要求“商业实质”，可能给人形机器人板块的估值降温，并改变风险投资与二级市场投资者对机器人初创企业的定价方式。它直接影响到至少 6 家企业的上市时间表与融资计划，也为其他资本密集、易被炒作的硬科技赛道树立了监管先例。 目前并未出台正式禁令，压力通过非正式渠道传导，因此企业仍可申报和上市，只是审批门槛被实质性抬高。监管关注的重点是政府支持类项目所产生的收入是否反映真实商业需求，以及部署规模与订单量能否支撑其寻求的估值；这与 2024 年以来中国 A 股 IPO 整体大幅收缩的趋严背景一脉相承。

telegram · zaihuapd · 9月21日 04:14

**背景**: 人形机器人是模仿人类形态、以双足行走的通用机器人，近年来因 AI 大模型与运动控制技术的进步而成为热门投资主题。IPO（首次公开募股）是企业通过在公开交易所发行股票来融资的方式。“窗口指导”是中国监管部门常用的一种非正式手段，通过约谈、电话和口头提示等方式影响发行节奏与定价，而不发布正式规则。宇树科技（杭州宇树科技有限公司）由王兴兴于 2016 年创立，最初以四足机器人起家，后推出 H1 等通用人形机器人产品。

## [亚马逊 Bedrock 接入 Kimi K3，中国大模型首次与海外云厂商落定分成合作](https://36kr.com/newsflashes/3992769217428488) ⭐️ 6.0/10

亚马逊云科技（AWS）宣布，中国公司月之暗面的开源大模型 Kimi K3 已正式上架 Amazon Bedrock，全球企业开发者可直接通过该平台调用。这也让此前传闻的“上架 + 按调用量分成”合作正式落地：月之暗面正与多家海外云厂商推进收入分成，据称这是中国大模型公司首次以分成模式向全球三大云厂商输出模型能力。 这为中国大模型出海提供了新的商业化模板：不再只靠自建 API 或私有化部署，而是借助西方超大规模云厂商的市场渠道变现，也让全球企业客户有了更熟悉、更合规的采购路径。若该模式在 AWS、Azure、Google Cloud 之间复制，可能改变开源中国模型与美国前沿实验室在企业渠道上的竞争格局。 Kimi K3 被描述为拥有 2.8 万亿参数的开源权重模型，原生支持视觉并具备 100 万 token 上下文窗口，因此 Bedrock 客户无需自行部署即可获得前沿级能力。该消息未披露定价、可用区域、SLA 或基准测试数据，月之暗面与 AWS 之间的分成比例也未公开。

telegram · zaihuapd · 9月21日 06:44

**背景**: Amazon Bedrock 是 AWS 于 2023 年推出的大模型托管服务，通过统一 API 提供多家 AI 厂商的基础模型，让企业无需自建基础设施即可开发生成式 AI 应用。月之暗面 2023 年成立于北京，是中国“AI 六小虎”之一，开发了 Kimi 聊天机器人与模型系列；2026 年 7 月发布的 Kimi K3 拥有 2.8 万亿参数，被称为史上最大的开源权重模型。所谓“开源权重”，指训练后的参数可下载，与仅能通过 API 使用的闭源模型相对。

## [蚂蚁集团整合支付宝、数字支付与芝麻信用，组建全新事业群](https://stock.10jqka.com.cn/20260921/c680135771.shtml) ⭐️ 6.0/10

蚂蚁集团 CEO 韩歆毅发布全员信，宣布支付宝事业群、数字支付事业群和芝麻信用事业部将合并组建为全新的支付宝事业群。2021 年 8 月加入蚂蚁集团、此前在阿里巴巴任职 20 余年的吴敏芝将出任新支付宝事业群总裁，并兼任蚂蚁集团 CPO（首席人才官）。 这是蚂蚁集团近年来最重要的组织架构调整之一，将支付、面向消费者的支付宝超级应用以及信用评分业务收拢到同一条汇报线下。此举意味着支付流量与信贷、消费服务将进一步打通，可能重塑蚂蚁在中国受监管的金融科技市场中与微信支付等对手的竞争格局。 此次调整通过内部全员信而非对外新闻稿发布，并未披露人员编制、事业群以下层级的汇报关系，以及数字支付事业群和芝麻信用事业部未来的品牌归属等细节。吴敏芝同时担任事业群总裁与蚂蚁 CPO，意味着她将同时掌管业务运营与人才组织两条线。

## [xAI 发布 Grok 4.7，主攻编程与知识工作](https://x.ai/news/grok-4-7) ⭐️ 6.0/10

xAI 发布了 Grok 4.7，官方称其为编程与知识工作领域最强的模型，价格与 Grok 4.6 完全持平：输入每百万 token 2 美元、输出每百万 token 6 美元。该模型已在 Cursor、Grok Build 以及 xAI API 等平台上线。 在宣称编程与长上下文能力提升的同时保持价格不变，说明 xAI 正围绕开发者与企业最关心的“单位任务成本”与其他前沿实验室正面竞争。同步登陆 Cursor 和 Grok Build，也表明编程智能体而非单纯的聊天，已成为模型发布的主要战场。 xAI 表示 Grok 4.7 采用了更大的基座模型并延长了强化学习训练，因此在自我校验和长上下文处理上更强；官方还宣称其在拒答与越狱抵抗方面表现最佳，并以邀请制向部分网络安全伙伴开放红队测试权限。值得注意的是，此次公告未公布任何基准测试数据，因此这些性能宣称尚无法被独立验证。

## [M6 Mac mini 曝料：多核追平 Intel 旗舰，GPU 接近 M4 两倍](https://www.bilibili.com/video/BV1JQhz6fE1x) ⭐️ 6.0/10

一份被归因于中国评测频道极客湾（Geekerwan）的跑分报告称，苹果 M6 Mac mini 采用台积电 N2 工艺，CPU 为 2+4+6 核心布局，超大核频率 4.8 GHz，GPU 为 12 核。报告数据显示其多核性能追平 Intel Panther Lake 旗舰（Core Ultra X9 388H），单核继续领先，多核较 M4 提升超过 50%，GPU 在光追和游戏方面约为 M4 的两倍。 如果数据属实，这将是 Apple Silicon 首次在 2nm 级工艺上于多核吞吐上追平 x86 旗舰笔记本处理器，同时保持低得多的功耗水平，这会给高端便携市场的 Intel 和 AMD 带来直接压力。GPU 性能翻倍还意味着苹果在游戏与光线追踪这一长期落后于独显的领域终于取得可信进展。 报告中的功耗数字相当保守——CPU 满载约 25W，双烤整机约 65W，而这恰恰是让对比变得棘手的地方：Panther Lake 的设计功耗跨度从 25W 一直到 80W 以上。该说法目前仍属未经证实的曝料，由聚合账号转发，未附带一手数据、测试方法或任何独立复现结果。

telegram · zaihuapd · 9月21日 16:32

**背景**: 台积电 N2 是其首个从 FinFET 转向环栅（GAAFET）纳米片晶体管的制程节点，台积电表示已于 2025 年第四季度进入量产。Intel 的 Panther Lake 一代以 Core Ultra X9 388H 为代表，包含性能核、能效核与低功耗能效核共 16 核，并集成 12 核 Xe3 级别核显，被 Intel 定位为对标 ARM 级能效的答卷。极客湾（Geekerwan）是中国大陆知名科技评测团队，其芯片跑分被广泛引用，因此即使是归于其名下但未经证实的曝料，在硬件社区中仍有一定分量。
