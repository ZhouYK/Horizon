## [MiniMax Launches Music3: AI Generates Up to 5-Minute Songs from Lyrics](https://www.aibase.com/news/30362) ⭐️ 8.0/10

MiniMax released MiniMax-Music3, an AI music generation model that produces up to 5-minute stereo songs from lyrics and text descriptions. The model outputs 32kHz 16-bit stereo WAV audio and uses a hierarchical autoregressive architecture built around an 8B global LLM initialized from Qwen3-8B. This is significant because generating coherent, musically structured songs of up to five minutes is a major advance over typical AI music models that produce short clips. It could broaden creative applications for musicians, content creators, and casual users, and demonstrates the growing use of large language models in audio generation. The model uses a hierarchical autoregressive architecture in which an 8B Global LLM predicts the first RVQ codebook per frame to capture long-range structure, initialized from Qwen3-8B. It outputs 32kHz 16-bit stereo WAV; official technical details and open-source release status have not been fully disclosed.

aibase · AIbase · Aug 14, 16:31

**Background**: Neural audio generation often relies on Residual Vector Quantization \(RVQ\), used in codecs like SoundStream and EnCodec, which break audio into multiple codebooks to reconstruct high-quality waveforms. Hierarchical autoregressive models generate music by first predicting low-level structural tokens \(e.g., the first RVQ codebook\) and then filling in finer detail in subsequent stages. MusicGen and similar models already use such token-based approaches, and the addition of an 8B LLM highlights the trend of scaling language models for audio tasks.

## [DeepSeek V4 Pro Launches on SiliconFlow with 1M Context and Low Cache Cost](https://www.aibase.com/news/30358) ⭐️ 8.0/10

DeepSeek V4 Pro \(version V4-Pro-0813\) made its Day-0 debut on SiliconFlow, offering a 1M-token context window, three reasoning intensity levels \(low/high/max\), and MIT open-source licensing. Pricing is set at $1.32 per million input tokens, $3.96 per million output tokens, and $0.44 per million cache-hit tokens. This release marks a significant step for open-source LLMs, combining a million-token context with adjustable reasoning intensity and aggressive cache pricing, making it highly attractive for coding, tool-calling, and agent workflows. It could intensify price competition in the LLM API market and push other providers to optimize caching and long-context performance. The model focuses on coding, tool calling, and agent workflows, with an MIT license that permits commercial use. The cache-hit price of $0.44 per million tokens is far below the normal input price, which can dramatically reduce real-world inference costs for workloads with repetitive prefixes, such as multi-turn agent interactions.

aibase · AIbase · Aug 14, 16:31

**Background**: An LLM&\#x27;s context window is the amount of text, in tokens, the model can consider at once; a 1M-token window allows it to process extensive documents or maintain long conversations. In LLM API pricing, a &\#x27;cache hit&\#x27; refers to prompt or prefix tokens the provider has already computed, so they are served at a lower price, making cache optimization a key lever for cutting costs. SiliconFlow is an AI inference platform that offers fast, low-cost access to 200+ open-source models, so hosting DeepSeek V4 Pro on Day-0 expands its ecosystem.

## [Samsung Cuts Chip Verification from a Month to Two Days with Claude Code](https://www.aibase.com/news/30346) ⭐️ 8.0/10

Samsung Electronics&\#x27; System LSI division adopted Anthropic&\#x27;s Claude Code for semiconductor verification, shortening the test cycle of a chip from over one month to two days, a 15x efficiency improvement. The tool, previously available to software developers, has now been expanded to the hardware field. This demonstrates that AI coding agents can deliver dramatic productivity gains in hardware verification, a traditionally manual and time-consuming domain. It signals that AI-assisted design is moving beyond software and could reshape semiconductor development workflows across the industry. In a custom SoC project containing 64 complex data paths, Claude Code completed the setup and verification of the virtual test environment in just two days. The tool was first made available to software developers in May of this year, and this adoption marks its expansion into hardware fields.

aibase · AIbase · Aug 14, 12:31

**Background**: Chip verification is a critical phase in semiconductor design that ensures the chip meets functional, performance, and power requirements before manufacturing. It typically involves testbench creation, test writing, simulation, and debugging, which are resource-intensive and time-consuming. A virtual test environment simulates the actual test setup, allowing verification to start earlier and cutting time-to-market. Claude Code is Anthropic&\#x27;s agentic coding tool that understands codebases, edits files, runs commands, and helps developers ship software faster.
