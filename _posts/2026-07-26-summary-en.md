## [Microsoft to Use TPM Chips to Block Pirated Windows Activation](https://www.techspot.com/news/113232-microsoft-using-tpm-chips-crack-down-pirated-windows.html) ⭐️ 7.0/10

Microsoft announced that it will enforce TPM-based hardware attestation for KMS \(Key Management Service\) servers, starting with Windows Server 2025. This mechanism verifies that the KMS server&\#x27;s hardware identity is certified by Microsoft before allowing batch activation requests. This move could effectively shut down many pirated activation methods that rely on fake KMS servers, significantly impacting the Windows piracy ecosystem. It also highlights Microsoft&\#x27;s ongoing efforts to enhance security through hardware-based verification. The TPM attestation requirement will be mandatory in the next version of Windows Server, with preparatory prompts rolling out in August 2026 for Windows Server 2025. It specifically targets the KMS activation loophole that has been exploited by tools like KMS38 and Online KMS.

telegram · zaihuapd · Jul 25, 15:55

**Background**: KMS \(Key Management Service\) is a Microsoft technology for volume activation of Windows and Office within organizations. It allows local activation without connecting to Microsoft&\#x27;s servers. Pirated activation tools have long used fake KMS servers to bypass activation. TPM \(Trusted Platform Module\) is a hardware security chip that can provide cryptographic attestation of system integrity. Microsoft&\#x27;s new &\#x27;TPM attestation&\#x27; ensures that only genuine KMS hosts with certified TPM hardware can process activation requests.
