## [Microsoft to Use TPM Chips to Block Pirated Windows Activation](https://www.techspot.com/news/113232-microsoft-using-tpm-chips-crack-down-pirated-windows.html) ⭐️ 7.0/10

Microsoft announced a new &\#x27;TPM attestation&\#x27; mechanism for KMS that cryptographically verifies the KMS server&\#x27;s hardware identity before allowing volume activation requests. This will become mandatory in the next Windows Server release and will be announced starting August 2026 for Windows Server 2025. This update directly targets the KMS-based piracy methods that have long been used to activate Windows without a legitimate license. If effective, it could block many existing activation tools, but the emergence of new exploits like TSforge shows the ongoing cat-and-mouse game between Microsoft and pirates. The TPM attestation uses hardware-based cryptographic proof to ensure the KMS server is genuine and not a fake server used by pirates. Microsoft already killed the KMS38 exploit in 2025, and the new TPM requirement is expected to make Online KMS methods less viable.

**Background**: KMS \(Key Management Service\) is a volume activation mechanism used by enterprises to activate Windows and Office products within their network without contacting Microsoft servers. Pirates have exploited KMS by running fake KMS servers that simulate valid activation, known as &\#x27;KMS activation.&\#x27; TPM \(Trusted Platform Module\) is a hardware security chip that provides cryptographic operations and attestation.

## [usbliter8 Jailbreak for iOS 27 Released, Only iPhone 11 Pro](https://github.com/34306/usbliter8-fun) ⭐️ 6.0/10

Developer 34306 released a full jailbreak for iOS 27 on iPhone 11 Pro using the usbliter8 SecureROM exploit, requiring a Raspberry Pi Pico 2 to enter Pwned DFU mode and flash custom firmware. This demonstrates a working exploit for an unpatchable hardware vulnerability in A13 chips, but its destructive nature \(data wipe, broken services\) makes it impractical for most users and highlights the trade-offs of hardware-level jailbreaks. The jailbreak wipes all device data, disables SEP, passcode, Wi-Fi, baseband, partially breaks Bluetooth, and blocks all Apple services; it adds kernel patches for USB restricted mode, sandbox execution, and AMFI trust cache bypass.

telegram · zaihuapd · Jul 25, 11:00

**Background**: usbliter8 is a publicly released BootROM exploit for Apple A12 and A13 chips that runs arbitrary code in SecureROM, the first code executed at boot. Because the vulnerability is in read-only memory, it cannot be patched via software updates. The exploit puts the device into Pwned DFU mode, allowing custom firmware to be loaded. This attack is similar in nature to the earlier checkm8 exploit but targets newer chips.
