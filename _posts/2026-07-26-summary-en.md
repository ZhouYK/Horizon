## [iOS 27 Jailbreak &\#x27;usbliter8&\#x27; Released for iPhone 11 Pro](https://github.com/34306/usbliter8-fun) ⭐️ 7.0/10

Developer 34306 published a full jailbreak solution for iOS 27 using the usbliter8 SecureROM exploit, currently limited to iPhone 11 Pro. The jailbreak requires a Raspberry Pi Pico 2 with RP2350 chip to trigger the exploit and install custom firmware. This jailbreak is significant because usbliter8 is an unpatchable hardware-level exploit in the SecureROM of Apple A12/A13 chips, affecting millions of devices. It opens the door for advanced security research and custom firmware development, but also raises security concerns for users of affected iPhones. The jailbreak wipes all device data, permanently disables SEP, passwords, WiFi, baseband, and most Apple services, with Bluetooth only partially working. It builds on wh1te4ever&\#x27;s usbliter8 project, adding kernel patches to bypass USB restricted mode, sandbox execution restrictions, and AMFI trust cache checks.

telegram · zaihuapd · Jul 25, 11:00

**Background**: The SecureROM \(BootROM\) is the first code that runs on an iPhone and is stored in read-only memory, making any exploit unpatchable without hardware changes. usbliter8 is only the fourth public BootROM exploit in iOS history, following checkm8, and affects devices with A12 and A13 chips such as the iPhone XS, XR, and 11 series. To use the exploit, the device must be connected via USB and put into a special &\#x27;pwned DFU&\#x27; mode using a Raspberry Pi Pico 2.

## [Microsoft uses TPM chips to crack down on pirated Windows activation](https://www.techspot.com/news/113232-microsoft-using-tpm-chips-crack-down-pirated-windows.html) ⭐️ 7.0/10

Microsoft announced that TPM-based attestation will be required for Windows Key Management Service \(KMS\) to verify that KMS hosts run on genuine, uncompromised hardware. The measure becomes mandatory in the next Windows Server release, with preparatory notices starting in August 2026 for Windows Server 2025. This move targets the KMS activation loophole widely exploited by pirates, potentially shutting down many fake KMS tools. However, the emergence of TSforge, a new exploit from the Massgrave group that claims to bypass the entire Windows DRM, suggests the cat-and-mouse game will continue. TPM attestation remains optional for current Windows Server versions but becomes mandatory in the next release. TSforge is said to be the most powerful public activator yet, supporting every Windows edition since Windows 7 and Office since 2013, with hardware-invariant activation requiring no network or services.

telegram · zaihuapd · Jul 25, 15:55

**Background**: KMS \(Key Management Service\) is a volume activation technology used by enterprises to activate Windows and Office on many devices with a single key. Pirates have long used unauthorized KMS servers to bypass licensing. TPM \(Trusted Platform Module\) is a hardware security chip that can verify system integrity. This change also follows recent attacks by the Russian Sandworm group that weaponized fake KMS activators against Ukrainian targets.
