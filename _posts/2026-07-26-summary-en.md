## [Microsoft to use TPM chips to block pirated Windows activation](https://www.techspot.com/news/113232-microsoft-using-tpm-chips-crack-down-pirated-windows.html) ⭐️ 7.0/10

Microsoft announced that it will require TPM-based attestation for KMS volume activation, starting with Windows Server 2025 and becoming mandatory from August 2026. This verifies the KMS server&\#x27;s hardware identity before allowing activation requests. This change could render many popular KMS-based activation tools ineffective, affecting enterprise piracy and the broader cat-and-mouse game between Microsoft and hackers. It also ties activation security more closely to hardware, raising the bar for bypass techniques. The new mechanism, called TPM attestation, will be enforced initially for Windows Server 2025 and later for client versions. However, the Massgrave group has already released TSforge, which claims to bypass the entire Windows DRM activation architecture by forging cache data directly in the Software Protection Platform.

telegram · zaihuapd · Jul 25, 15:55

**Background**: KMS \(Key Management Service\) is a Microsoft technology for volume activation in enterprise environments, where clients activate against an internal KMS server. Pirated activations have long exploited fake or hijacked KMS servers. TPM \(Trusted Platform Module\) is a hardware security chip that can attest to system integrity. The new TPM attestation ties activation to a verified hardware identity, making it harder to spoof.

## [iOS 27 Jailbreak Using usbliter8 Exploit Released for iPhone 11 Pro](https://github.com/34306/usbliter8-fun) ⭐️ 6.0/10

Developer 34306 released a jailbreak for iOS 27 using the usbliter8 SecureROM exploit, currently only supporting iPhone 11 Pro. The method requires an external RP2350-based Raspberry Pi Pico 2 to enter PWN DFU mode and install custom firmware with kernel patches. This jailbreak demonstrates the first public exploitation of the usbliter8 vulnerability on iOS 27, but its severe functionality breakage and limited device support reduce practical usefulness. The release highlights ongoing security research into Apple&\#x27;s SecureROM, though the claimed iOS 27 version raises credibility concerns. The exploit leverages the unpatchable usbliter8 SecureROM vulnerability affecting Apple A12 and A13 chips. The jailbreak wipes all data and disables SEP, passcode, WiFi, baseband, and most Apple services, with Bluetooth only partially functional. Patches include bypassing USB restricted mode, sandbox execution restrictions, and AMFI trust cache checks.

telegram · zaihuapd · Jul 25, 11:00

**Background**: SecureROM is the first immutable code executed during Apple device boot, establishing the chain of trust. The usbliter8 exploit achieves arbitrary code execution inside SecureROM on A12/A13 devices, similar to the older checkm8 exploit but for newer chips. AMFI \(Apple Mobile File Integrity\) enforces code signing, and trust caches list approved binaries that can run with platform privileges. The RP2350 chip is a dual-core Raspberry Pi microcontroller used here as a hardware tool to trigger the exploit.
