## [Black Forest Lab FLUX3 Debuts: 20s Audio+Video Generation](https://www.aibase.com/news/29880) ⭐️ 8.0/10

Black Forest Labs released FLUX3, a unified multimodal model that jointly generates images, videos \(up to 20 seconds\), and synchronized audio using the Self-Flow self-supervised flow matching framework. FLUX3 outperforms existing models like Grok and Seedance in video and audio quality, representing a significant step toward true multimodal AI that seamlessly handles multiple data types natively. The model supports text-to-video, image-to-video, keyframe transitions, and multilingual dialogue, with native synchronized audio output. It builds on the FLUX series using Self-Flow, which combines flow matching with self-supervised feature reconstruction.

aibase · AIbase · Jul 25, 10:15

**Background**: Self-Flow is a self-supervised flow matching paradigm that integrates representation learning within a generative framework. Unlike traditional diffusion models, it decouples data distribution learning from representation learning, allowing each token to have a different noise level during training. This enables the model to jointly understand and generate across image, video, audio, and motion domains.

OvisOCR2 is designed as an end-to-end parser that takes a document page image and generates a Markdown representation preserving natural reading order, covering text, formulas, tables, and visual regions. Despite its small size \(0.8B parameters\), it achieves state-of-the-art results on OmniDocBench.

OmniDocBench is a comprehensive benchmark introduced at CVPR 2025 that evaluates document parsing across diverse document types including academic papers, textbooks, and handwritten notes.

This benchmark addresses the fragmentation and lack of transparency in current coding agent evaluations by providing a unified platform across four work domains. Its contamination-resistant question design ensures that assessments truly measure generalization and transfer abilities rather than rote memorization. WorkBuddy Bench includes repository-level code engineering, front-end web artifacts, office automation, and security scenario tasks. **Background**: Coding agents are AI systems that autonomously perform software engineering tasks. WorkBuddy Bench aims to provide a more realistic and trustworthy evaluation by combining multiple domains and using anti-memorization techniques.
