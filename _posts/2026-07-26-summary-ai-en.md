## [Black Forest Labs Releases FLUX3 Multimodal Model with Native Audio](https://www.aibase.com/news/29880) ⭐️ 8.0/10

Black Forest Labs has released FLUX3, a unified multimodal model that can generate up to 20-second videos with synchronized audio in a single pass, using the novel Self-Flow self-supervised flow matching framework. It claims to significantly outperform previous models like Grok and Seedance in video and audio generation tasks. FLUX3 represents a major step toward unified multimodal generation, combining image, video, and audio in one model, which could streamline content creation workflows. Its native audio-video synchronization and strong performance could impact industries like filmmaking, advertising, and virtual reality. FLUX3 is built on the Self-Flow architecture, which uses per-token timestep conditioning to handle different noise levels across tokens during training. It integrates dedicated encoders/decoders for image, video, audio, and motion codecs, enabling tasks like text-to-video, image-to-video, keyframe transitions, and multilingual dialogue.

aibase · AIbase · Jul 25, 10:03

**Background**: Self-Flow is a self-supervised flow matching framework that combines the flow matching objective with a self-supervised feature reconstruction objective, eliminating the need for external models or supervision. Flow matching is a generative modeling technique that learns to transform noise into data by modeling the probability flow, and self-supervised learning allows the model to learn representations from the data itself. Multimodal models like FLUX3 aim to understand and generate content across multiple modalities \(e.g., text, image, video, audio\) simultaneously, enabling more natural and integrated AI systems.

## [Ruff v0.16.0 expands default rules from 59 to 413](https://simonwillison.net/2026/Jul/25/ruff/#atom-everything) ⭐️ 7.0/10

Ruff v0.16.0, released on July 23, 2026, increases the number of default enabled linting rules from 59 to 413, causing widespread CI failures for projects using unpinned Ruff dependencies. This dramatic expansion of default rules means that many Python projects will now catch severe issues like syntax errors and runtime errors without any configuration, significantly improving code quality but also requiring developers to adapt their workflows. The new default rules include checks such as DTZ005 \(datetime.now without tz\), BLE001 \(catching blind Exception\), and B018 \(useless attribute access\). Astral&\#x27;s new affiliation with OpenAI suggests the output is designed to feed AI coding agents.

rss · Simon Willison · Jul 25, 22:44

**Background**: Ruff is an extremely fast Python linter written in Rust, designed to replace multiple tools like Flake8, isort, and Black. By default, it previously enabled only a small subset of its 968 total rules, but v0.16.0 changes that to 413 rules, catching many common issues that previously required explicit configuration.
