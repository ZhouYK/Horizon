## [路透：投资者将 Anthropic IPO 估值预期下调至 1.5 万亿美元](https://www.reuters.com/business/finance/investors-temper-anthropic-ipo-valuation-expectations-over-revenue-growth-2026-10-15/) ⭐️ 8.0/10

路透社 2026 年 10 月 15 日报道称，部分投资者已将 Anthropic 的 IPO 估值预期从此前的约 2 万亿美元下调至约 1.5 万亿美元。值得注意的是，Anthropic 第三季度营收达 168 亿美元、环比增长 45%，并实现经调整后盈利和季度现金流转正。 Anthropic 的上市原本被预期为史上最大规模的 AI IPO 之一，因此估值预期下调意味着公开市场投资者开始要求看到收入可持续性、毛利率和资本效率的证明，而不再单纯为增长买单。该报道明确将其视为智谱、MiniMax、Kimi（月之暗面）和 DeepSeek 等 AI 公司的估值压力测试，这些公司在后续融资或上市时可能面临更严苛的审视。 估值预期下调主要归因于三点：增速放缓、前沿模型之间的价格竞争加剧，以及算力投入带来的沉重资本压力。搜索结果显示，Anthropic 曾在 H 轮融资中取得 965 亿美元估值，并于 2026 年 6 月向美国证券交易委员会（SEC）提交了保密的 S-1 注册文件，因此 1.5 万亿美元这一数字相较其最近一轮私募估值仍是极大的倍数。

**背景**: Anthropic 是 Claude 系列大语言模型的开发方，与 OpenAI、Google DeepMind 并列美国头部前沿 AI 实验室。IPO 估值预期本质上是投资者对该公司股票公开交易时整体市值的估算，通常基于对未来收入和利润率的预测，而非当前盈利。这对 AI 模型公司尤为关键：算力与云资源成本往往吞噬其 30%–40% 的收入，显著压缩毛利率，而上游算力芯片厂商可获取 70%–90% 的毛利，这种利润分层使模型层业务在公开市场投资者眼中显得重资产、烧钱。

## [快手可灵 Kling 4.0 全量上线，支持 4K HDR 与 MCP](https://mp.weixin.qq.com/s/Dn2jAxV0m6kpt7y4edRvdg) ⭐️ 7.0/10

10 月 15 日，可灵 Kling 4.0 正式在 klingai.com 全量上线，创作页面同步进行整体升级，带来更灵活自由的创作体验。官方同时表示，后续将推出 4K 与 1080p 的 10-bit HDR 格式输出，Kling 4.0 能力已接入 MCP 与 CLI，面向企业与开发者的 API 服务也将于近期开放。 可灵是当前商业化文生视频模型的头部选手之一，4.0 全量上线会抬高整个 AI 视频生成领域的质量基线。更重要的是 MCP/CLI 接入与即将开放的开发者、企业 API，这意味着可灵正从一个面向消费者的网页工具，转变为可被智能体、IDE 和内部流水线直接调用的可编程能力模块。 该公告内容简短且偏宣传性质，未披露技术基准、模型规模、分辨率档位或定价信息，4K/1080p 10-bit HDR 输出与开发者、企业 API 均只是“后续推出”“近期开放”，尚未正式可用。10-bit HDR 支持意味着更宽的色深与高光动态范围，面向的是专业后期与调色流程，而非随手的社交短片。

telegram · zaihuapd · 10月16日 04:30

**背景**: 文生视频模型输入一段文字提示词即可生成动态影像，可灵是快手在这一赛道上的产品，同场竞技的还有 Runway、OpenAI 的 Sora 和 Google 的 Veo。多模态 AI 指能够处理并生成文本、图像、音频、视频等多种数据类型的系统，而这正是视频生成模型内部必须完成的工作。MCP（模型上下文协议）是 Anthropic 于 2024 年 11 月推出的开放标准，用于规范 AI 模型连接外部工具与数据源的方式；接入 MCP 后，助手或智能体无需编写定制胶水代码即可调用可灵，CLI 则提供等效的命令行调用能力。10-bit HDR 视频相比常见的 8-bit 视频能记录更多色彩与亮度信息，在支持 HDR 的屏幕上呈现更平滑的渐变和更亮的高光。

## [阶跃星辰发布 Step 5 Preview 智能体旗舰模型](https://huggingface.co/stepfun-ai/Step-5-Preview) ⭐️ 7.0/10

阶跃星辰（StepFun）在 Hugging Face 上发布了旗舰模型 Step 5 Preview，采用稀疏 MoE 架构，总参数 6000 亿、激活参数 270 亿，最高支持 100 万 token 上下文，并原生接收文本、图像和视频输入。官方称该模型在软件工程、长周期智能体执行以及专业领域任务上表现领先，尤其在金融场景中表现突出。 这是一次来自中国厂商的前沿级发布，把稀疏 MoE 的效率、超长上下文与多模态能力专门针对智能体负载结合在一起，而这种组合正成为 2025—2026 年智能体模型的标志性设计范式。构建编码智能体、电脑操作（computer-use）智能体或金融分析流水线的团队因此多了一个可直接部署的前沿选项，并且它兼容标准的 OpenAI 风格 API，这将加剧同类开源权重 MoE 模型之间的竞争。 该模型可通过 vLLM 或 SGLang 以 OpenAI 兼容 API 方式部署，采用 StepFun Model License 1.0 许可，这是厂商自定义许可而非标准的 OSI 认证开源协议。它明确标注为“Preview”（预览）版本，其在软件工程、长周期智能体任务和金融领域的能力陈述均为官方自评，目前尚无第三方独立评测。

telegram · zaihuapd · 10月16日 06:36

**背景**: 稀疏 MoE（Mixture-of-Experts，混合专家）是一种模型架构：模型内部包含大量专门化的子网络（“专家”），但每个 token 只被路由到其中一小部分，因此总参数量可以非常庞大，而每个 token 实际消耗的算力却相对有限——这也是本次 6000 亿总参数与 270 亿激活参数之间区别的由来。100 万 token 的上下文窗口意味着模型可以一次性吞下超长输入，例如完整的代码仓库或成批的长文档，这对于必须记住此前多步操作的长周期智能体尤为关键。智能体（Agent）指的是能够进行规划、调用工具并执行多步动作的模型，而不仅仅是回答单个提问。vLLM 与 SGLang 是当前主流的开源推理与服务框架，负责高吞吐批处理和提供 OpenAI 兼容接口，使得这类模型可以较容易地投入生产部署。

## [法院文件曝光：Telegram 向美国政府交出用户数据](https://www.404media.co/heres-what-telegram-giving-data-to-the-u-s-government-looks-like/) ⭐️ 7.0/10

新公开的法院文件显示，Telegram 在回应美国法院命令时，向执法部门提供了一名用户的手机号、用户 ID 和 IP 地址；Telegram 在信函中称此次提供系「自愿」，同时表示不承认受美国司法管辖。该案涉及被控参与 2023 年 10 月 7 日袭击以色列事件的 Mahmoud Al-Muhtadi，文件还显示截至今年 1 月，Telegram 已向美方提供 2253 名用户的数据。 这一披露与 Telegram 长期公开塑造的「隐私优先且不受美国司法管辖」的形象直接矛盾，也加剧了围绕通讯应用如何应对政府数据请求的争论。这可能影响 Telegram 约十亿用户对其的信任，并引来监管机构、隐私倡导者和安全研究人员更严格的审视。 信函的措辞值得注意：Telegram 将此次交出数据描述为「自愿」而非被强制，同时又否认受美国管辖；而截至 1 月已披露 2253 名用户数据这一数字，说明此事远非孤立个案。所提供的手机号、用户 ID 和 IP 地址，正是即便不含聊天内容也能识别账号持有人并大致定位其位置的那类元数据。

telegram · zaihuapd · 10月16日 14:57

**背景**: Telegram 是一款以端到端加密的「秘密聊天」、大型群组和频道著称的通讯应用，长期把自己宣传为不易屈服于政府数据要求的平台。这里的「司法管辖」指的是某国法院是否有权强制一家公司配合的法律问题；Telegram 主张自己不受美国管辖，但美国执法部门仍可发出能触及该公司的命令。执法部门通常索取的是手机号、IP 地址这类用户元数据，因为这类信息足以在不暴露聊天内容的情况下识别嫌疑人。
