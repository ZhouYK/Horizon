OpenAI has deployed an internal &quot;control room&quot; system inside its research infrastructure that can stop a risky AI agent task from receiving further model outputs within 35 seconds of a halt command. Every training, evaluation, and data-processing job is tracked by a unique task ID, and the inference engine verifies whether that task is still authorized before serving each request. As AI agents gain the ability to run long, autonomous, multi-step tasks, the ability to reliably halt a misbehaving run becomes a core safety primitive rather than a nice-to-have. OpenAI publicly detailing concrete infrastructure — task-level authorization and pre-inference gating — gives other labs and enterprises a reference design for containing agentic systems before an incident escapes the lab. OpenAI says the remaining latency comes from a cache of authorization requests and that it is working to drive that delay to zero, meaning the 35 seconds is a worst-case bound rather than typical response time. All frontier reinforcement-learning runs will additionally get independent model monitors that inspect behavior and raise alarms when potential problems are detected.

Reinforcement-learning agents are especially hard to contain because a single run can involve thousands of model calls over hours, and a bad trajectory may only become visible partway through. The &quot;independent monitor&quot; idea echoes a broader industry push, reported in late 2026, for outside safety evaluators to get continuous access to AI development environments.

## [Claude Code leaks 2,539 real credentials across 1,994 GitHub repositories](https://www.ithome.com/1/024/888.htm) ⭐️ 7.0/10

Security firm Apiiro found 2,539 real credentials — including database passwords and API tokens — exposed in 1,994 public GitHub repositories, after more than 100,000 Claude Code local settings files were uploaded to public repos, roughly 1,100 of which contained secrets. Anthropic said it is studying preventive measures and is considering building secret scanning directly into the tool. This is a tool-specific leakage vector rather than a generic misconfiguration: the AI coding agent itself persists approved shell commands, complete with inline tokens, into a settings file that frequently gets committed alongside project code. Anyone using Claude Code in a shared or public repository is potentially affected, and the finding pushes AI coding vendors to treat credential hygiene as part of the product rather than the user&\#x27;s responsibility. The leaks trace back to the project-local settings file \(settings.local.json\), which records commands a user approved via &quot;don&\#x27;t ask again&quot; so the agent can re-run them without prompting; in many cases Claude Code commits that file itself without user input. Apiiro&\#x27;s GitHub search turned up 104,185 copies of the file across 103,617 repositories, and researchers caution that default secret-scanning rulesets often miss passwords embedded inside command syntax, so pre-commit hooks and CI checks need custom rules covering full history.

telegram · zaihuapd · Nov 10, 11:20

**Background**: Claude Code is Anthropic&\#x27;s agentic coding tool that can read files and run shell commands in a developer&\#x27;s workspace. Its configuration is layered across user-level, project-level and project-local settings files, and settings.local.json is intended to hold machine-specific preferences that should normally be excluded from version control via .gitignore. When a user approves a command with &quot;don&\#x27;t ask again&quot;, Claude Code writes that command into the local settings file so it can run unattended later — which is how secrets quoted inside commands end up stored on disk. Apiiro is a security research firm specializing in software supply chain and code risk.

## [MiniMax open-sources H3 Image, bringing 4K generation to ~10 seconds](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image) ⭐️ 7.0/10

Open-weight models that can hit true 4K resolution quickly are still rare, and combining that with multi-reference conditioning and editing makes H3 Image practical for production image pipelines rather than demos. With weights on Hugging Face plus aggressive API pricing, teams that were locked into closed image APIs now have a self-hostable or cheaply callable alternative for high-resolution work. Pricing is roughly $0.069 per 4K image in standard mode, with a launch-week promotional rate of about $0.034, and the model is already wired into MiniMax Code and Hailuo \(海螺\) products. telegram · zaihuapd · Nov 10, 15:39

**Background**: MiniMax H3 Image belongs to the H3 model family from MiniMax, a Chinese AI company, and is described as an &quot;open-weight&quot; release — meaning the trained weights are published so others can run or fine-tune the model, though that is not the same as fully open source \(which would also include training data and code under a permissive license\). Text-to-image diffusion-style models convert a prompt into an image; reference-based generation additionally conditions the output on one or more supplied images, which is how editors keep a subject, style or product consistent.
