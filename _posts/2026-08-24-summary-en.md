## [Grok Bot 0.18.0 Source Reconstructed and Open-Sourced After Source Map Blunder](https://x.com/b_nnett/status/2091630242792112480) ⭐️ 6.0/10

Cursor team&\#x27;s Grok bot 0.18.0 accidentally enabled runtime source maps, enabling a user named Bennett to reconstruct the full backend source and publish it on GitHub. Bennett then extended the code with custom routes for Codex and Claude Code, plus local Docker support. This incident highlights how runtime source maps can inadvertently expose proprietary source code, with real security and open-source implications. It also shows the growing trend of reverse engineering AI coding tools, following similar exposure of Claude Code. The reconstructed version does not include the frontend, but can run using the official packaged frontend and remains modifiable. Bennett&\#x27;s version adds custom routes \(Codex and Claude Code\) and the ability to use a local Docker container instead of a remote sandbox.

telegram · zaihuapd · Aug 24, 10:36

**Background**: Runtime source maps are files that map minified or transpiled JavaScript back to the original source, used for debugging in production. When accidentally enabled in a deployed application, they allow anyone to inspect or reconstruct the original code. Similar incidents have occurred before, such as Anthropic accidentally exposing Claude Code&\#x27;s source code through source maps.
