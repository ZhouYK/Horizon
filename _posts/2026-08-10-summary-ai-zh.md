## [英伟达发布首款开源全双工语音模型 VoiceChat 11B](https://www.aibase.com/news/30220) ⭐️ 8.0/10

英伟达发布了其首款开源端到端全双工语音对话模型 NemotronLabs VoiceChat 11B。与传统的 ASR-LLM-TTS 级联架构不同，它通过单一网络实时进行流式语音理解和生成。 这标志着对话式 AI 的重大转变，实现了无需轮流等待的自然、实时双向语音交互。它为全双工语音交互设立了新的开源基线，可能加速语音智能体和实时助手的应用普及。 该 11B 参数的模型支持实时音频对话、工具调用，以及约 450 毫秒的轮流响应延迟。它作为 NVIDIA 的 NemotronLabs 系列一部分在 Hugging Face 上提供，是目前最大的开源全双工语音模型之一。

GitHub Models 已于 2026 年 7 月 30 日正式退役，其统一 LLM API 在 GitHub Actions 中已不可用。这导致依赖该服务的 CI/CD 工作流（如 Simon Willison 的研究仓库）出现故障。 许多开发者之所以在 GitHub Actions 中使用 GitHub Models，是因为它能直接复用现有的 GitHub API 密钥，让 LLM 驱动的自动化变得简单且免费。该服务的退役迫使开发者改用其他 LLM 提供商（如 OpenAI），可能增加 GitHub 上 AI 自动化工作流的成本或使用门槛。 GitHub 于 2026 年 7 月 30 日通过变更日志宣布了退役。作者的工作流现已改用带有月度支出限制的 OpenAI API 密钥，并使用 GPT-5.6 Luna 生成摘要；他推测停用原因是编码智能体模式带来了过高的成本压力。

rss · Simon Willison · 8月9日 22:48

## [用 zlib/zstd 压缩 SQLite 文本历史原型](https://simonwillison.net/2026/Aug/9/sqlite-text-history-prototype/#atom-everything) ⭐️ 7.0/10

西蒙·威利森原型验证了一种把全文修订历史存为 zlib 或 zstd 压缩的 JSON 字符串数组、再放入 SQLite 的方案。在模拟 1000 次修订的测试中，20.4 MB 的原始修订文本用 Zstandard 压缩后只有约 80.3 KB。 在关系型数据库中高效存储修订历史一直是个难点，尤其当文档较长时。这一方法可大幅降低存储开销，为 Web 应用、Wiki 和协作工具带来实用的编辑历史追踪能力。 原型把压缩后的 JSON 数组存在 BLOB 列中，时间戳则单独用未压缩的 Unix 整数数组保存。为了避免每次编辑都重新压缩整个历史，GPT-5.6 Sol 建议把历史拆成多行，每行最多存放 128 个修订版本或 3 MB 未压缩的 JSON。

rss · Simon Willison · 8月9日 22:05

**背景**: zlib 是一套跨平台的通用无损压缩库，实现了 DEFLATE 算法，广泛用于 PNG、HTTP、Git 和 PostgreSQL 等场景。Zstandard（zstd）是 Facebook 推出的新一代实时压缩算法，可以在压缩速度与压缩比之间灵活取舍，通常对相同输入能获得比 Snappy 更高的压缩率。这个原型背后的核心假设是：同一文档的不同版本包含大量重复字符串，因此把整个 JSON 文本数组压缩起来能消除绝大部分冗余。

## [AI 信用评分的跨境法律灰色地带](https://news.google.com/rss/articles/CBMixAFBVV95cUxQREltVFhrWHFVX0VhN3FocEdrNExQTVVmdTlOdEhNSnhLbWl2ZUE1RmF6QURvVnAwWlV6WXV6bHRKb2VYUC0zcDBnYy1LX29kLUthM2c3ZVNIaDFfX0M5U2t3UUt0b2NMaE1NZkhTOVVQMTNmcTUzX2l0cUM3ME5HZHZqQ3FFVTdCbG1Ic3k5Q2dJcWJzM1ZTUmI0NnF0WklJcnU1Vjg5cjdPOUZsalVwR18wTXdiOEhUNjdLTTlpeF8tTmFD?oc=5) ⭐️ 7.0/10

《哥伦比亚法律评论》发表了一篇分析文章，探讨 AI 信用评分中未解决的法律问题，重点关注贷款机构在跨国运营时面临的各国监管制度冲突。 随着 AI 信用评分在全球日益普及，缺乏统一规则给金融科技公司带来合规风险，也使消费者享有的保护参差不齐。这项分析对监管机构、贷款机构以及关注 AI 治理和公平信贷获取的人士都具有参考价值。 据报道，该文章聚焦算法透明度、反歧视义务和跨境数据传输等法律灰色地带。它指出，欧洲综合性的数据保护规则与美国行业性监管框架等不同做法，可能给 AI 驱动的贷款机构带来相互冲突的要求。

google\_news · culawreview.org · 8月10日 21:11

**背景**: AI 信用评分利用机器学习算法评估贷款申请人，通常除了标准信用记录外还会纳入非传统数据。与传统评分不同，这些模型可能不透明，引发问责和偏见方面的担忧。国际借贷活动会放大这些问题，因为数据会跨境流动，而不同司法辖区的法规各不相同。
