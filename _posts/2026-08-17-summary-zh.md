## [通过 GPT-5.6 Sol 配置在 Codex 中启用 1M Token 上下文窗口](https://x.com/thsottiaux/status/2089082893804896524) ⭐️ 6.0/10

Tibo 分享了一种在 Codex CLI 中启用 1,000,000 Token 上下文窗口的配置方法。该方法在 ~/.codex/config.toml 中设置 model、model\_context\_window=1000000 和 model\_auto\_compact\_token\_limit=900000，然后重启客户端。 这使得 AI 辅助编码工具能够充分利用 GPT-5.6 Sol 接近 1.05M Token 的容量，在单次会话中处理整个代码仓库或长文档。使用大型代码库的开发者可以减少上下文截断问题，并获得更连贯的长期编辑效果。 该设置必须放在 config.toml 的顶层，也可以作为命令行参数用于单次会话。自动压缩阈值为 900,000 Token，意味着代理会在达到 1M 限制前压缩上下文；GPT-5.6 Sol 的原生窗口为 1,050,000 Token。

telegram · zaihuapd · 8月17日 00:47

**背景**: GPT-5.6 Sol 是 OpenAI 于 2026 年 7 月发布的旗舰模型，拥有 1,050,000 Token 的上下文窗口，并在编程基准测试中创下最新纪录。Codex CLI 是 OpenAI 的轻量级编码代理，在终端本地运行，可读取代码仓库、提出补丁并执行命令。通过配置上下文窗口大小，用户可以控制代理在会话中保留多少项目上下文。

## [ChatGPT 上线 Computer History：记录点击与按键，不截屏](https://www.theverge.com/ai-artificial-intelligence/980742/chatgpts-computer-history-tracks-your-clicks-and-keystrokes) ⭐️ 6.0/10

OpenAI 在 macOS 版 ChatGPT 应用中推出了“Computer History”功能，这是一个可选开启的功能，会记录用户的点击和按键，以建立活动时间线，用于模型训练和自动化任务。它采集的是“事件”数据，而非截屏。 该功能让 ChatGPT 能更深入地学习用户的工作方式，并有望实现自动化操作，对标微软 Windows Recall 等同类功能。同时，由于它会记录设备上的详细交互，引发了关于隐私保护的新讨论。 Computer History 默认关闭，用户可排除特定应用和网站、手动删除历史记录，并可忽略无痕或隐私标签页。OpenAI 表示该功能不截取图像、视频或音频，只记录交互事件。

telegram · zaihuapd · 8月17日 04:16

**背景**: 这一功能与 Windows 11 的 Recall 相似，但 Recall 依靠定时截取活动屏幕快照来帮助用户回溯之前的操作，而 Computer History 只记录交互事件。该时间线可供 ChatGPT 和 OpenAI 的编程智能体 Codex 调用，帮助助手理解用户的工作流程并提出自动化建议。
