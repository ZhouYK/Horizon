## [《EVE Online》启动向 Python 3 的迁移](https://simonwillison.net/2026/Aug/25/eve-online-move-to-python-3/) ⭐️ 7.0/10

《EVE Online》宣布开始从 Stackless Python 2.7 迁移到 Python 3，首先对 240 万行 Python 代码运行 futurize 脚本。该过程还包括人工审查约 20,000 处 Python 2 与 Python 3 行为差异的地方。 这对 Python 社区来说是一次里程碑式的迁移，因为《EVE Online》是规模最大、运行时间最长的基于 Python 的游戏系统之一。该项目将为我们仍停留在 Python 2 的其他组织提供宝贵的实战经验。 该公告尚未说明《EVE Online》将如何替换 Stackless Python 本身，但去年团队曾介绍“Scheduling in Carbon: Leaving Stackless Python Behind”，并为其新游戏《EVE Frontier》开源了 carbonengine/scheduler 库。迁移将首先使用 futurize，然后进入行为差异的人工审查阶段。

rss · Simon Willison · 8月25日 22:59

**背景**: Stackless Python 是 Python 解释器的增强版本，增加了称为 tasklet 的轻量级微线程，可以在没有操作系统线程开销的情况下运行大量并发任务。《EVE Online》自 2003 年上线以来一直使用它，该项目已于 2025 年 2 月正式停止维护。Python 2.7 已于 2020 年停止支持，因此迁移到 Python 3（以及可能替换 Stackless）对游戏的长期可维护性至关重要。
