## [Anthropic Launches Free OSS Scanner for Open-Source Vulnerabilities](https://www.anthropic.com/research/launching-opt-in-vuln-finding-service-for-open-source) ⭐️ 8.0/10

Anthropic announced OSS Scanner, a free, opt-in vulnerability scanning service that uses Claude models to scan eligible open-source repositories and generate reports. Over the past six months the service surfaced more than 29,000 candidate vulnerabilities, roughly 6,000 of which were human-reviewed, and 85 of 97 early high- or critical-severity findings met its disclosure process requirements. It signals a shift toward LLM-assisted security research at scale, potentially giving under-resourced open-source maintainers free access to vulnerability triage that would otherwise require costly commercial tools or scarce security expertise. Since open-source components underpin most commercial software, vulnerabilities found here could affect downstream users far beyond the projects themselves. Reports are generated by Claude and other models without human review, include reproduction steps, vulnerability explanations, and patch suggestions where possible, and may therefore contain errors. Eligible projects&\#x27; core maintainers can apply by submitting a GitHub pull request to Anthropic&\#x27;s oss-scanner repository.

**Background**: OSS Scanner is a service from Anthropic, the company behind the Claude family of large language models, that scans critical open-source repositories for security vulnerabilities. Large language models can read and reason about source code well enough to flag suspicious patterns, which makes them useful for triaging bugs at a scale traditional static analysis tools struggle to match. Open-source projects are often maintained by small volunteer teams with little security budget, so free automated scanning addresses a well-known gap in the software supply chain.

## [China&\#x27;s FAST Telescope Finds First Native Pulsar Triple System](https://nao.cas.cn/news/gd/202610/t20261009_8289939.html) ⭐️ 8.0/10

Chinese and European scientists independently confirmed that the pulsar PSR J0435+3233, discovered by China&\#x27;s FAST telescope, belongs to the first known native triple system still in an evolutionary stage, made up of a pulsar, a white dwarf and a Sun-like star. The result was published in The Astrophysical Journal Letters on October 9, 2026. Triple systems containing a pulsar are extremely rare, and one that formed natively and is still evolving gives astronomers a natural laboratory for testing stellar evolution models and gravitational dynamics in a three-body setting. It also showcases FAST&\#x27;s growing role in discovering exotic pulsar systems and adds to its record as the world&\#x27;s most productive pulsar-hunting telescope. The system&\#x27;s inner orbit has a period of about 8 days while the outer orbit takes roughly 73.5 years, meaning the outer companion orbits far too slowly for the full cycle to be observed directly. The finding was reported on the National Astronomical Observatories of China website and also posted to arXiv, and it was independently corroborated by European researchers rather than resting on a single team&\#x27;s analysis.

telegram · zaihuapd · Oct 9, 05:14

**Background**: FAST \(the Five-hundred-meter Aperture Spherical radio Telescope\) is the world&\#x27;s largest single-dish radio telescope, built in a natural basin in Pingtang County, Guizhou Province, and it is particularly sensitive to the faint radio pulses of neutron stars. A pulsar is a highly magnetized, rapidly spinning neutron star only about 10-15 km in radius that sweeps a beam of radio emission past Earth like a lighthouse, and a white dwarf is the dense leftover core of a star that has exhausted its fuel. A &quot;native&quot; triple system means all three stars were born together in the same star-forming cloud and have stayed gravitationally bound ever since, which is notable because most such systems are disrupted or lose a member before reaching this stage.

## [Telegram Desktop Flaw Lets Malicious tg:// Links Steal Any File](https://telegram.me/zaihuapd/44307) ⭐️ 8.0/10

Telegram Desktop versions below 7.2.9 contain a critical vulnerability tracked as CVE-2026-107181, in which clicking a malicious tg:// link can silently exfiltrate arbitrary files without any user confirmation. Telegram fixed the issue in version 7.2.9, released on September 17, by removing the interpret: handler and adding proper escaping for command separators. Because Telegram Desktop is widely used on desktops and the attack requires only a single click on a crafted link, the flaw could lead to theft of sensitive data such as SSH keys, browser sessions, crypto wallets and even Telegram session files, enabling full account takeover. It highlights how seemingly small input-handling oversights in messaging clients can have outsized security consequences for millions of users. The root cause is that a semicolon inside a tg:// link was not escaped and was interpreted as a separate IPC command by Telegram Desktop&\#x27;s single-instance mechanism, allowing the attacker to reach the interpret: handler, which can read and upload local files to an attacker-controlled channel. Users are advised to upgrade to 7.2.9 or later, be wary of unusual tg:// links, and enable a local password.

telegram · zaihuapd · Oct 9, 09:51

**Background**: tg:// is Telegram&\#x27;s custom URL scheme that lets links open specific actions or chats directly inside the app. Telegram Desktop runs as a single instance and uses inter-process communication \(IPC\) to forward commands from a newly launched process to the already running one, so malformed input in a link can be abused as command injection. The interpret: handler is an internal mechanism that can read and upload local files, which made it a dangerous target once an attacker could invoke it through a crafted link.

## [Amazon Builds 1,000th Satellite, Nears Commercial Space Internet Launch](https://arstechnica.com/space/2026/10/amazon-builds-1000th-satellite-is-weeks-away-from-space-internet-rollout/) ⭐️ 7.0/10

Amazon has produced its 1,000th satellite at its Kirkland, Washington factory for the Amazon Leo low-Earth-orbit broadband constellation, and the company says commercial service is only weeks away. The satellites will launch aboard an upcoming ULA Vulcan return-to-flight mission, with a second Vulcan being prepared to loft more satellites in 2026. Reaching 1,000 satellites and moving to commercial service makes Amazon the most serious challenger yet to SpaceX&\#x27;s Starlink in consumer satellite broadband, turning a long-delayed project into a real market rivalry. Wider competition could affect pricing, coverage and service terms for users in rural and underserved regions, and pressures other LEO players such as OneWeb. Amazon Leo is licensed by the FCC for 3,236 satellites spread across three altitude shells at roughly 590 km, 610 km and 630 km. Timing is tight because ULA paused Vulcan launches in February 2026 after a solid rocket booster issue, so the next flight counts as a return-to-flight mission rather than a routine commercial launch.

telegram · zaihuapd · Oct 9, 04:30

**Background**: Low Earth orbit \(LEO\) satellite constellations place many satellites a few hundred kilometers up so that signals travel with very low latency and at least one satellite is always overhead; because a single satellite only covers a small moving area, hundreds or thousands are needed for global coverage. Amazon Leo was long known as Project Kuiper before being rebranded, and it is operated by Kuiper Systems LLC, an Amazon subsidiary, following Starlink and OneWeb into the market. Its rockets, ULA&\#x27;s Vulcan Centaur, replace the Atlas V and Delta IV and use Blue Origin BE-4 engines; Vulcan first flew in January 2024 and was certified for U.S. national security missions in 2025, but booster problems have slowed its cadence.

## [JetBrains Releases Mellum2.1, a 12B Open-Source Coding Model for Agents](https://blog.jetbrains.com/ai/2026/10/mellum2-1-gets-to-work-a-fast-open-model-for-coding-agents/) ⭐️ 7.0/10

JetBrains released Mellum2.1, an Apache 2.0 licensed open-source coding model built on a 12B-parameter mixture-of-experts architecture with only 2.5B active parameters, trained with reinforcement learning in real sandbox environments. Model weights are now available on Hugging Face, and the model is designed to explore codebases, edit files, and verify its own changes for locally run coding agents. A permissively licensed, small-active-parameter coding model from a major IDE vendor lowers the barrier for enterprises and individual developers to deploy private, self-hosted coding agents without sending code to third-party APIs. It also signals that JetBrains is positioning itself in the agentic coding tool race alongside providers of both proprietary and open-weight models. The 12B MoE design with 2.5B active parameters keeps inference cost and memory footprint low enough for local deployment while retaining a large total parameter pool. Reinforcement learning was expanded from short-term code completion into the core training component, with targeted reinforcement across millions of software engineering and algorithm sandboxes.

telegram · zaihuapd · Oct 9, 07:30

**Background**: Mixture-of-experts \(MoE\) architectures split a model into many specialized sub-networks, or experts, and route each token to only a few of them, so a large total parameter count can be served at the compute cost of a much smaller model. Coding agents are AI systems that go beyond autocomplete: they read repositories, run commands, edit files, and iterate on their own output, which requires reinforcement learning inside sandboxed environments where mistakes cannot damage real systems. Apache 2.0 is a permissive open-source license that allows commercial use, modification, and redistribution.
