## [MiniMax 发布 Music3：根据歌词和描述生成最长 5 分钟歌曲](https://www.aibase.com/news/30362) ⭐️ 8.0/10

MiniMax 发布了 MiniMax-Music3，这是一个 AI 音乐生成模型，可根据歌词和描述文本生成长达 5 分钟的 32kHz 16-bit 立体声 WAV 歌曲。该模型采用分层自回归架构，其中的 80 亿参数全局大语言模型基于 Qwen3-8B 初始化。 Music3 将 AI 音乐生成从短视频片段推向更长的完整歌曲，基于歌词生成的能力对创作者尤其有价值。它也展示了通用大语言模型（如 Qwen3-8B）融入音频生成系统的潜力。 该模型输出 32kHz 16-bit 立体声 WAV，并通过一个从 Qwen3-8B 初始化的 80 亿参数全局大语言模型逐帧预测第一级 RVQ 码本，从而捕捉歌曲的长程结构。其核心技术路径是分层自回归建模与残差向量量化（RVQ）相结合。

aibase · AIbase · 8月14日 16:31

**背景**: AI 音乐生成系统通常使用神经音频编解码器，通过残差向量量化（RVQ）将波形压缩成离散 token，再由语言模型预测这些 token。类似 MusicLM 的分层自回归生成方法会在多个 token 层级上建模音乐，从语义结构层到声学细节层。MiniMax-Music3 延续了这一技术路线，并利用基于 Qwen3-8B 的大语言模型来引导歌曲的整体结构。

智谱发布了 GLM-5.3，这是一个开源编程模型，沿用与 GLM-5.2 相同的基座模型，仅通过后训练扩展就实现了显著的性能提升。内部编程评测显示其比 GLM-5.2 提升约 50%，成为最强的开源编程模型。 这次发布表明，扩展后训练计算量而不只是基座模型规模，也能显著提升大模型的能力上限，这对无法承担漫长预训练成本的组织尤为重要。同时，它也加剧了开源权重编程模型这一快速发展的 AI 细分赛道上的竞争。 据称，性能提升来自更大的长时程（long-horizon）环境、更丰富的环境类型以及更长的后训练阶段。公开基准测试成绩也很亮眼，但文章未说明具体使用了哪些编程基准或给出具体分数。

aibase · AIbase · 8月14日 14:31

## [三星用 Claude Code 将芯片验证从一个月缩短至两天](https://www.aibase.com/news/30346) ⭐️ 8.0/10

三星电子系统 LSI 部门引入 Anthropic 的 Claude Code 进行半导体验证，将某些芯片的测试周期从一个月以上缩短至两天，效率提升约 15 倍。在一个包含 64 条复杂数据路径的定制 SoC 项目中，Claude Code 仅用两天就完成了虚拟测试环境的搭建与验证。 这表明 AI 编程工具不仅能加速软件开发，也能显著提速硬件工程，可能重塑半导体设计流程，帮助公司更快推出芯片并缓解验证瓶颈。 Claude Code 最初于今年五月面向软件开发者发布，现已扩展至硬件领域。该定制 SoC 项目包含 64 条复杂数据路径，该工具在两天内完成了虚拟测试环境的搭建和验证。

aibase · AIbase · 8月14日 12:31

**背景**: 芯片验证是在制造前发现并修正设计缺陷的过程，以避免生产出无法正常工作的微芯片。Claude Code 是 Anthropic 推出的智能体式编程工具，能理解代码库、编辑文件并运行命令，帮助开发者更快交付。将此类 AI 助手应用于硬件验证是一个新兴且前景广阔的方向，因为验证是半导体设计中的主要瓶颈。
