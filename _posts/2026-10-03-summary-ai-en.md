## [AI agents burn 5x more tokens than humans, straining KV cache and RAM](https://news.google.com/rss/articles/CBMirgJBVV95cUxNVVVhN3dDRnN1RVBpNC1pMG52TTczcTNoc09VdkE3TUNZbmIxaXdnWXQ2WkM1cmJJNXVpQXk5U2RDWDZ0SEFNeHRuU2loS05SdTRacGlmUDdmMi1RSE5EXzhmcC13ZkhJS2stNll1UjNoOExkYnR1eHV5U0RoT1ptVzd3bzNOTW1obldoRW9JMFFvM3J3WjRZM2RaUHZYeGxMb2g1SWwxM1FhRmxHUXZBUER6SkkwaTRud2c5bGdTQlJQRmNXcG91c1FaVlNoNWpRc0plbk1VTDdtNDMycmJUUW1ZUHN2S1VUeXBnOTdBeks0QzBoUGJibHJDNkFGa0xpdDUyZjgyUGQwc05vSUh1emlnVGZOaEVTRWU1cWhUajM1WUpTVUJMRndYeVJ3UQ?oc=5) ⭐️ 7.0/10

According to a Tom&\#x27;s Hardware report, AI agents now consume roughly 5x more tokens than human users for comparable tasks, a figure trending toward 10x as cached prompts explode in size. The report attributes the surge to agents repeatedly rereading context they have already processed, which dramatically increases KV cache demand. Because KV cache lives in fast memory, spiraling agent workloads translate directly into higher demand for RAM and GPU memory, intensifying an already worsening memory shortage. This affects cloud providers&\#x27; serving costs, hardware procurement plans, and ultimately the price and latency of agentic AI products. The core inefficiency is that agents are described as mostly rereading what they have already seen rather than generating genuinely new content, so the growth is concentrated in input tokens and cached context rather than output. Supporting research on agent token spend has found agentic tasks consuming orders of magnitude more tokens than ordinary code chat or reasoning.

google\_news · Tom&\#x27;s Hardware · Oct 3, 13:10

**Background**: Large language models generate text one token at a time using the Transformer architecture, and for every token they compute Key \(K\) and Value \(V\) matrices that attention uses to relate the new token to earlier ones. A KV cache stores those K and V results so the model does not have to recompute the entire prior context at each step, trading memory for speed. Agentic systems run long, multi-step loops that accumulate huge contexts, so their KV caches grow far larger than those of a single chat turn, and that cache must be kept in fast, scarce memory such as GPU VRAM or system RAM.

## [Brands Rethink Sales Pitches as AI Agents Start Shopping](https://news.google.com/rss/articles/CBMiggFBVV95cUxOZG53TThGaFdFbkFQQ21CNm9HNVd4VlBnMWkxS2RUdDBVUVVqLTVHQV90VEYyVVo2U1pVeEh5b2laaV9JRkxkT050emZZcVFSM0FhSUdjcWJHcVhOX0xmSnFBczlnVlUwQ0c2b0hGR2N4TUVhX3YxUWxzWGxwY0labElR?oc=5) ⭐️ 6.0/10

The New York Times reports that brands and retailers are changing how they market and describe their products because AI shopping agents, rather than humans, are increasingly the ones reading product listings and making purchase decisions. Marketing language, product data and site content are being reworked so that autonomous agents can parse and rank them. This marks a shift toward &quot;agentic commerce,&quot; where a growing share of purchase intent is mediated by software rather than human browsing, potentially reshaping search advertising, affiliate marketing and retail SEO. Brands that fail to make their catalogs machine-readable may simply disappear from the consideration set, while platforms that control the agents gain substantial gatekeeping power over consumer demand. The coverage is largely trend-level rather than technical: AI shopping agents typically take a natural-language intent \(for example, &quot;best running shoes under $150&quot;\), search across stores, compare price, fit and reviews, and on some platforms complete checkout using emerging agent payment protocols. Because agents rank and filter listings programmatically, structured product data, explicit attributes and machine-friendly descriptions matter far more than persuasive human-facing copy.

**Background**: An AI agent is a program that pursues goals, uses external tools and takes multi-step actions with some autonomy, typically driven by a large language model; this contrasts with the narrow, chat-style AI that became widespread in 2023. Agentic commerce is the emerging application of such agents to shopping, combining generative AI, autonomous agents, APIs and digital payment rails so that searching, comparing and paying can happen without real-time human involvement. That is why product copy written to persuade a person is being rewritten to be legible to a machine.
